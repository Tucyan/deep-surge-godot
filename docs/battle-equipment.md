## 固定基础行动

攻击（原出拳）：1 AP，造成基础1伤害；保留原有角色伤害修正。格挡：1 AP，获得本战斗回合1护盾。两者可重复使用，不进入普通手牌，不占容量，不参与弃牌。

每点护盾抵消1点对生命的直接攻击伤害，未抵消部分扣生命。护盾不代替筏格修复，不抵消中毒、污染等持续损失。来源、数量、到期回合分别记录，优先消耗最早到期的层；本回合护盾在敌人行动完成后失效，战后全部清理。

## 资源组合

选择真实资源实例，再选择攻击或格挡，预览后确认。每次最多消耗一张资源，共1 AP；取消、无效目标、旧revision及费用不足不扣资源或增益。只有木头、废铁、绳索、塑料、布条开放组合。

| 资源 | 攻击 | 格挡 |
| --- | --- | --- |
| 木头 | 基础1伤害、本回合1护盾 | 本回合3护盾 |
| 废铁 | 基础2伤害 | 本回合2护盾，本回合首次近身攻击反击1次、1伤害 |
| 绳索 | 基础1伤害，下次敌人攻击减伤1 | 对特定特殊攻击施加束缚，否则下一攻击减伤2、最低0 |
| 塑料 | 无组合 | 本回合2护盾，敌行动后剩余最多1点保留至下回合敌行动结束，仅延续一次 |
| 布条 | 无组合 | 本回合1护盾，清除一种中毒/流血类身体异常，不清潮蚀污染牌，不回血 |

绳索束缚：啃筏者取消预告的筏格啃咬，生命伤害保留；水母毒刺变成不附带中毒的普通攻击。其他敌人的攻击需要明确配置才可取消特殊效果。同一次攻击不能重复束缚，特殊效果取消与默认减伤不同时获得。

啃筏行为必须单独显示目标筏格及格损效果，不能把攻击力换算成损伤格数。意图预览不能抽取活跃规则随机数。

## 发电机增益

发电机消耗尸体燃料，在每轮开始、开放导航前推进生产；完成产出后选择领取动力强化、屏障强化或设备增压。存储槽独立于普通手牌，不覆盖已有牌。按用户后续确认：满槽仍可产出，超出长期容量的新增增益标为临时，到产出当轮的轮末结算时消失。轮末清到期临时增益，上一轮弃牌通过后才执行新一轮生产；领取时保留原期限，不能借选择效果刷新期限。领取可选内容不会重新抽取产出。无燃料时暂停生产进度。

| 增益 | 开发默认效果 |
| --- | --- |
| 动力强化 | 本次有效直接攻击伤害+2，不增加反击伤害 |
| 屏障强化 | 本次护盾行动额外获得2点护盾，额外层持续至下回合敌人行动结束 |
| 设备增压 | 滤水器、土盆、捕捞网的下一次正常生产额外产出1份，不重置进度，每生产周期仅一次 |

先选增益，再选有效行动，预览后确认。增益本身0 AP，行动仍收原费用；每行动最多一张增益，与资源组合可同时使用。只在行动成功后消费，取消不提前存入已生效状态。设备增压对发电机自身和箱子无效。

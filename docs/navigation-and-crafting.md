# Godot V0.2 航行前操作与合成界面

2026-10-15：新增场景内设备拖放、格子操作小面板和单个扩建虚影确认，所有动作仍复用下文原安装/升级/修复/扩建命令。扩建费用提取为原值常量，未改变木头2/AP1；详见[木筏直接交互](raft-direct-interaction.md)。

2026-10-14 用户修订，仅适用于当前 Godot 工程。2026-10-15 补充：合成改为全屏，所有 UI 倍率均四列两行、每页最多 8 项；右上 X 关闭，删除面板内返回首页。材料、配方、AP、禁用原因及翻页规则保持原逻辑。

- 每轮开始进入 navigation 时刷新基地 AP（包括有效休整加成），首次导航同样可操作。手牌、生存物资、合成、设备操作在导航/准备/收尾开放。
- 出发支付原有航耗，不再刷新 AP；合成与安装分别收费，避免航行前合成后重复获得行动点。轮末结算及弃牌仍阻挡操作。
- 合成入口固定在底部左侧；手牌排列与拖动预留该区域。右侧阶段、卡牌信息与事件选择框延伸至手牌区上方。
- 合成弹窗四列两行，每页最多八项，库存/AP、效果、材料持有/需求、禁用原因由当前只读视图生成。当前内容表恰有八项；更多内容自动分页，不增加新配方。科技/教学限制继续执行。
- 设备卡双击发出 `install {uid, auto:true}`，规则层按 cells 原有顺序找到首个完好空位，花费 1 AP 并移出该实例。不使用装饰筏根，不覆盖设备，不使用破损/脱落格。无法安装时命令回滚并显示原因。
- 单击查看、长按拖动、轮末弃置及战斗出牌保持各自手势；双击安装只在可进行基地操作的阶段触发。

验证入口：`tests/test_navigation_actions.gd`、`tests/test_craft_grid.gd`、`tests/test_auto_install.gd`。合成界面 GPU 截图由 `test_craft_grid.gd -- --capture` 保存，含 1280×720 与 1600×900。分页测试以测试夹具添加第九项，确认第二页单项及返回第一页，不修改正式内容表。

同日底部布局修订：1600×900 逻辑画布中，卡牌区左侧 292、右侧距边 64，底侧距边 18，高 220；行动点移至左下，按 0.75 比例绘制，下面为直径 128 的圆形合成按钮。容量徽章以卡牌区水平中心为锚点，圆角背景只显示 `当前容量/上限`，主界面删除原「手牌」和贝币余额文字。容量仍按原规则计算，物资卡/贝币卡规则不变。GPU 截图与手牌拖动、设备双击、两种分辨率边界验证已重新运行。

2026-10-17。首页“回溯潮涌”是已接触剧情的回顾入口，替换旧的最近结算报告/结局列表；不改变终局两页结算。

卡片使用上图、下方剧情标题和类别说明。整个卡片可点击，图片与标题点击均进入同一段剧情。桌面宽度每页三列两行，较窄布局两列两行，以页码/上一页/下一页浏览，不使用滚动列表。

- **特殊剧情：潮水之后（开局序章）**：初始即收录，计入剧情总数。完整重播五幕原旁白、逐字狸语和 BGM，完成或退出回到回廊；不改首次启动的已观看记录。
- **航程剧情**：只收录剧情模式中已进入的正式叙事。`entered` 仅归档当前 runtime 已显示的文本前缀；`completed` 归档已走过的全部正文；`bypassed` 不解锁。当前实际已产生的结果文字可追加回顾，不显示未选分支/未来剧情。
- 现有正式剧情 AssetId 只有纯色占位，没有独立插画，因此首版统一复用用户提供的海上船队分镜作封面；有正式插画后按 AssetId 替换。序章卡使用木筏苏醒分镜。卡片和回顾封面等比显示，去除原图黑色留白。
- 回顾保留旁白打字/狸语和音乐。点击、空格、回车先补全文字，再次推进；“返回回廊”按钮和 Esc 直接结束。只读播放不触发核心 dispatch，不重复选择、扣费、奖励或消耗随机。

独立适配器 `adapters/story_gallery_store.gd` 保存本机 `user://story-gallery-v1.json`（schema 1），包含已遇剧情的标题、图片 AssetId、正文快照和结果快照。归档从真实 GameSession snapshot 读取，游戏核心状态不被修改；成功 UI 命令后及成功恢复存档时收录，开启持久化时原子写入。新航程保留此前已收录内容，重新启动可恢复。损坏/未知 schema 的归档保留原文件并报错，不覆盖为新文件。测试关闭 persistence 时仅使用内存。

本地回廊档案与游戏存档分离，不新增游戏存档字段，不改变内容版本/Agent协议。没有本地回廊档案时，只能从当前有效游戏存档补回已记录的剧情；此前已经覆盖掉的历史航程无法凭空恢复。Agent 独立运行不会写 UI 本机归档。

`pages/story_gallery.gd` 负责展示，`flow_app.gd` 负责路由和只读回放；`presentation/opening_intro.gd` 提供 `persist_completion`、`playback_data` 和 `exit_label` 复用参数。主场景根节点保留原 App 接口，`presentation/game_bootstrap.gd` 继承 App，在首次序章结束后初始化正式界面。

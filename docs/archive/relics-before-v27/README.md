# v27之前的藏品旧案归档

本目录是历史资料，不定义当前游戏行为，不参与运行内容加载。

- `relics.json`：替换前的完整定义表，包括旧6件启用遗物和禁用的旧设想。
- `collectible-effects.md`：替换前的v26效果契约快照。
- 根仓库 `docs/archive/relics-before-v27/relics_design_table.csv` / `.pdf`：用户要求归档的原设计表。

2026-10-20用户明确要求“藏品需要全部重新设计，归档旧案”。当前20件全新方案见 [藏品与寻物节点](../../relic-expedition.md)，运行定义仅来自 `content/data/relics.json`。旧保存不迁移，拒绝时保留原文件。

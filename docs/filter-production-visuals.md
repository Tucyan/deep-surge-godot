# 一级滤水器生产状态 · 2026-10-15

沿用土盆的生产预告外观：按下一航行轮开始时是否达到周期预先显示，实际淡水在下一轮开始、开放导航前进入手牌。不是战斗回合，不新增储水、领取或额外产出命令。

| 实际等级/进度 | 外观与标签 |
|---|---|
| 1级，progress=0 | 开口空接水桶，“过滤中”；下轮开始仅累积进度 |
| 1级，progress>=1 | 接水桶内有蓝色水面，“下轮开始产水”；下轮开始产出并重置进度，回到空桶 |
| 2、3级 | 保持有水外观，每轮产水，不新增高等级等待阶段 |
| 破损 | 保留当前模型但变暗、停用；标签改为“过滤暂停 / 停用·待修补”，不承诺下轮产水 |

仅 `presentation/raft_state_models.gd` 读取既有 level/progress 选择模型。`production_stage` 是场景元数据，不进入 GameState 或存档。周期[2,1,1]、产量[1,1,2]、AP与随机未变。

保留旧高位滤桶、支架、滤布与出水嘴，接水桶由实心柱改为有壁厚的开口桶。空桶与有水模型的其余几何完全一致，盆底与木座顶保持1厘米间隙，避免共面闪纹。水面为静态外观标记，不是额外手牌物资，也未加入滴水动画。

稳定ID：`model.raft.module.filter`（有水）、`model.raft.module.filter-waiting`（空桶）。编辑源、生成和验证见 [资产源记录](../asset-sources/filter-states-v1/README.md)、[验收记录](../evidence/filter-v1-verification.md)。

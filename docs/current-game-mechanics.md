# 当前游戏机制梳理（以 Godot 代码为准）

核对日期：2026-10-16。范围：`deep-surge-godot`，内容版本 `godot-flow-v02-11`；节点与商店以当前 Godot 代码为准。

本文描述当前程序行为，不把旧 Three.js 规则、V0.2 设计目标、历史文档、测试夹具中的原型视为已上线玩法。文字与代码冲突时，以 Godot 实际执行分支及其加载的 JSON 为准。本轮经济试测已修改规则，验证范围见 [经济 v11 验证](../evidence/economy-v11-verification.md)。

## 1. 游戏结构与完整循环

当前是围绕航行节点推进的资源生存游戏。手牌同时承担库存、消耗品、设备部署物资和战斗消耗品的职责；木筏设备把制造投入转为后续补给、战斗供给或容量。

- **挑战模式**：开局随机决定 10～15 次航行；普通轮最多提供三个候选节点，最后一站固定 Boss。可以离开遭遇；最后没有击败 Boss 则是 `withdrawn`，击败并完成轮末流程才是 `survived`。
- **剧情模式**：固定 15 次移动，1～4 站教学/路线选择，5～14 站普通节点与夜间系统，第 15 站处理剧情终点。第一层结束为 `chapterComplete`，保留活动局，第二层没有开放。

常规流程：

```text
新局起手 → 导航（可先行动）→ 选目的地并支付航耗
→ 准备（可继续行动）→ 进入事件 → 选项/交易/战斗
→ 结果文字确认 → 收尾（可用剩余AP）
→ 剧情模式按日程进入夜间 → 轮末老化与临时增益到期
→ 超限才手动弃牌 → 下一轮刷新AP、设备生产、领取涌泉、生成导航候选
```

基地操作在 `navigation/preparation/aftermath` 开放；剧情、商店交互、战斗、夜间、弃牌阶段不开放普通制造与设备经营。打开/关闭面板不改变规则阶段，隐藏事件面板也不能跳过事件。

基地 AP 默认 3，进入新轮导航时设为上限；出发、进节点、战后不刷新。战斗 AP 独立，默认每回合 3，进入战斗及每次敌人回合结束后设为上限。

自动推进有两个入口：战斗 AP 为 0 且没有有效免费牌时自动结束战斗回合；收尾没有有效基地操作时自动结束航行。**AP 为 0 本身不足以自动结束**，免费安装、恢复、加燃料等仍可保留操作机会；有 AP 时常驻打捞本身就能保留收尾行动。满属性恢复牌仍可手动消耗，但不算阻止自动推进的有效恢复。

依据：[会话入口与初始状态](../core/game_session.gd)、[航行规则](../core/run_rules.gd)、[自动推进](../core/auto_progress.gd)、[有效操作查询](../core/action_query.gd)。

## 2. 生存系统

### 基础属性与出身

未叠加出身、局外成长时：

| 属性 | 初值 | 上限 |
|---|---:|---:|
| 生命 HP | 12 | 12 |
| 饱食 | 40 | 100 |
| 水分 | 40 | 100 |
| 精神 SAN | 80 | 100 |
| 基地 AP / 战斗 AP | 各 3 | 各 3 |
| 手牌容量 | — | 10 |

恢复受对应上限限制。提高食水或精神上限不等于开局填满；局外修正执行后会将开局生命填满。

| 出身 | 当前实现 |
|---|---|
| 强壮之人 | 生命及上限 +4（无成长时 16）；食水上限各 +10，当前食水仍各 40 |
| 愚者 | 通用 `ChangeCurrent` 负精神效果减少 5；无燃灯移动 SAN 扣 10；夜间调查成本减少 5。选项明确支付的 `statCosts.sanity` 不享受通用减免 |
| 多动症 | 基地、战斗 AP 上限各 +1 |
| 囤积癖 | 手牌容量 +1 |
| 战斗狂热 | 普通撤退免生命代价 |
| 无魔之人 | 免疫敌方施加的中毒/畏惧战斗状态；Boss 生成污染牌不在该免疫分支内 |

### 航耗与死亡判定

每次选择目的地并移动：

1. 饱食 -30、水分 -30，最低为 0。已有 `avoidWave` 时本次各扣 25，随后清除标记。
2. 精神通常 -15；愚者且没有燃灯时 -10。
3. 每个完好且有燃料的灯恢复 `15 + 5×(等级−1)` 精神，并消耗 1 燃料。多个灯逐个结算；愚者有燃灯时仍先扣 15。
4. 扣航耗后食水为 0，各造成 1 生命损失，合计最多 2。刚好降到 0 也触发。
5. 生命为 0 则死亡，精神为 0 则精神崩溃；两者都结束本局。移动先结算灯恢复，再统一检查存活。

食水不足不扣 AP，不在轮末再次扣航耗；战斗回合也不推进食水消耗和筏格老化。当前没有独立的疾病、鲜度腐坏或通用低 SAN 负面藏品系统。

### 恢复来源

| 来源 | 效果/费用 |
|---|---|
| 淡水 | 0 AP，水分 +40，消耗一张 |
| 食用植物 | 0 AP，饱食 +40，消耗一张 |
| 灯火余温 | 0 AP，精神 +15，消耗一张 |
| 包扎包 | 0 AP，生命 +3，消耗一张；不安装，不追加布条 |
| 营地休整 | 免费三选一：生命+4、食水各+20、精神+20；或食水牌各1；或精神+25且后续两轮基地AP上限+1（不补当前AP） |
| 夜间休息 | 每晚主要行动一次：生命 +3、食水各 +50、精神 +35 |

四种生存牌可以在基地操作阶段及战斗中使用；夜间服务发放的是牌，夜间本身没有普通出牌入口。

依据：[初始属性/出身](../core/game_session.gd)、[航耗与恢复执行](../core/run_rules.gd)、[生命参数](../core/health_balance.gd)、[卡牌数值](../content/data/cards.json)、[夜间配置](../content/data/story_config.json)。

## 3. 卡牌、库存与资源经济

### 获得与容量

五种基础资源为木头、废铁、塑料、绳索、布条；怪物尸体也是 `resource` 类，但不在五种基础资源抽取池中。

- 起手自选 1～5 张基础资源，每种最多 2 张；选几张就只发几张，不补齐。零选择为五种等权随机 7 张，可重复，不受每类 2 张限制。
- 首轮无涌泉。后续每轮先生产，再领取**固定木头 1 + 五种基础资源等权有放回随机 1 张**，共 2 张，可再抽木头。
- 海面打捞：导航/准备/收尾常驻，1 基地 AP 随机获得一张基础资源，可重复至 AP 不足。
- 资源转化：1 基地 AP，投入 3 张永久资源牌，获得指定一种基础资源 2 张；投入实例不能重复，种类可以相同，尸体也能投入。核心支持 `count` 批量，Agent v1 操作目录只提供一次 3 换 2。

通常每个手牌实例占 1 容量，设备牌未安装也占容量。全部贝币合占 1 容量。弓弩生产的箭按其 `stack_limit` 分组向上取整计算容量；普通资源的视觉叠牌不减少逻辑容量。发电机增益储存在设备中，不占普通手牌容量；固定攻击/格挡也不占容量。

轮内允许超限，生产、补给、奖励不因超限被拒收。只有轮末老化与增益清理后才检查；超限进入 `discard`，此时只能整理，不能用恢复牌或制造腾位置。弃到达标立即开始下一轮，新的生产和涌泉可以再次造成轮内超限。贝币弃置会丢掉全部余额。污染牌不能直接弃置。

### 制造与使用

当前 12 个配方都需 **1 基地 AP**，材料如下；配方生成的是一张牌，不自动安装：

| 产物 | 材料 |
|---|---|
| 灯 | 木头 1、废铁 1 |
| 滤水器 | 塑料 2、木头 1 |
| 土盆 | 塑料 1、木头 1 |
| 包扎包 | 布条 2、木头 1 |
| 弓弩 | 废铁 1、绳索 1、木头 1 |
| 矛架 | 木头 2、废铁 1；需长矛工艺科技 |
| 护盾架 | 木头 2、废铁 1 |
| 发电机 | 木头 1、废铁 2、绳索 1 |
| 捕捞网 | 木头 1、绳索 2 |
| 储物箱 | 木头 2、绳索 1 |
| 拆除牌 | 木头 1、废铁 1 |
| 修补包 | 废铁 1、绳索 1 |

拆除牌使用再花 1 AP，移除指定设备，选其原配方中的一种材料回收 1 份；不会按升级投入全额退还。修补包使用再花 1 AP，修复一个破损格。因此制造和使用行动牌分两次付 AP；制造和安装设备则是制造 1 AP、安装 0 AP。

JSON 配方的 `tool: handtool` 字段目前没有实际工具持有检查；不能据此推导已实现工具系统。没有普通牌库循环抽牌、弃牌堆洗回或随机高级合成。

依据：[库存及容量](../core/inventory.gd)、[资源转换/制造/行动牌](../core/run_rules.gd)、[全部配方](../content/data/recipes.json)。

## 4. 木筏与设备

### 格子状态

初始四个功能格为 `(2,0)、(0,1)、(1,1)、(2,1)`；`(0,0)、(1,0)` 为装饰筏根，不能安装或扩建。每个功能格最多一台设备，没有整船耐久，也没有当前设备独立 HP。

- `intact`：允许安装，设备生效。
- `damaged`：不能装新设备，原设备保留但停用；生产进度暂停，储物箱容量加成失效，发电机储存增益也无法调用。
- `detached`：格子及设备消失；可以花扩建费用在合法邻接位置重新建格，原设备不恢复。

通用事件 `DamageCell` 从当前外围非脱落格随机选一格：完好→破损，已破损→脱落。啃筏者另有专用逻辑，只选择完好的外围格并造成破损。

第 N 轮破损，在 N+2 轮结束时仍未修复则老化脱落；受损当轮不计后续轮，战斗回合不计。修复恢复整格及原设备，不额外重置设备进度。

| 操作 | 费用与约束 |
|---|---|
| 安装 | 消耗设备牌，**0 AP**，完好空格 |
| 直接修补 | 木头 1 或绳索 2，另付 1 AP |
| 修补包 | 消耗该牌和 1 AP，不追加材料 |
| 扩建/重建 | 木头 2、1 AP，正交邻接在位格，坐标须在许可范围 |
| 升级 | 1 AP，合并同类同级设备；1→2 可吃手牌设备或另一台 1 级设备，2→3 需另一台已安装的完好 2 级设备 |

升级上限为 3；1→2 支持“制作一件并升级”的原子操作，需配方材料和 2 AP。被合并设备格变空，它的燃料、进度与增益不转移给目标；目标自身数据保留。

默认扩建坐标范围 3×3，扣两格装饰实际最多 7 功能格；购买许可后为 4×4，实际最多 14 功能格。扩建不是无限地图，也未要求全体格子保持连通；当前没有“功能格归零立即失败”的单独判定。

### 各设备的实际收益

| 设备 | Ⅰ级 | Ⅱ级 | Ⅲ级 |
|---|---|---|---|
| 灯 | 每次移动 +15 SAN | +20 SAN | +25 SAN |
| 滤水器 | 每推进 2 次轮初生产得淡水 1 | 每轮初淡水 1 | 每轮初淡水 2 |
| 土盆 | 每推进 2 次轮初生产得食物 1 | 每轮初食物 1 | 每轮初食物 2 |
| 弓弩 | 每个战斗回合发临时箭 1，单张占 1 容量 | 同量，2 箭占 1 容量 | 同量，3 箭占 1 容量 |
| 矛架 | 每场开战给一张临时矛，伤害 3 | 同量，伤害 5 | 同量，伤害 5 |
| 护盾架 | 每战斗回合开始给当回合盾 1 | 相同 | 相同 |
| 捕捞网 | 每轮初随机基础资源 1 | 相同 | 相同 |
| 储物箱 | 容量 +3 | +6 | +9 |
| 发电机 | 每 2 次有燃料的轮初推进产增益 1；长期槽 1 | 每次推进产 1；槽 1 | 每次推进产 1；槽 2 |

轮初生产只在真正进入下一轮时推进，安装不立即生产，查看/读档不生产，终局或章节停点没有额外生产。Ⅰ级滤水器若第 N 轮安装，通常到 N+2 轮开始首次产水；Ⅱ级则 N+1 轮开始产水。

灯投入木头 1 得 2 燃料，尸体 1 得 3 燃料；加燃料不花 AP，只有移动消耗灯燃料。发电机只收尸体，每具 +3 燃料；每完成一个生产周期扣 1，而不是每次进度推进扣 1。

发电机产出先为待领取，领取时免费选择：动力强化（一次攻击直接伤害 +2）、屏障强化（符合护盾条件的行动另加 2 盾，存续至下一回合敌方行动结束）、设备增压（滤水器/土盆/捕捞网下次完成生产多 1 份）。同一个生产设备不能同时挂两份待生产增压；增压附加时消耗储存增益，下次产出后清除加成。

长期槽满仍产出一份临时增益，代码设 `expires_voyage=当前新轮编号`，即该轮末到期；不覆盖长期增益。多台设备收益可叠加。并非所有设备升级都有额外收益，不能把升到 3 级等同于必然增强。

依据：[设备操作及轮初生产](../core/run_rules.gd)、[设备参数](../content/data/equipment.json)、[增益参数](../content/data/boosts.json)、[战斗设备供给](../core/battle_rules.gd)。

## 5. 导航与节点事件

### 候选生成

候选从当前合格的正式节点定义中按类别权重抽取（supply25/trade10/service15/risk10/battle20/camp10/shop10）。挑战前两航次优先保证免费食水选择；之后不保底免费收益。每次最多3种节点，同族变体不挤占多个位置，营地与商店各最多一项。类型内部权重为1÷(1+3×已访问次数)，上一站同族另乘0.25。访问次数、冷却、最低航次不合格的内容不进入候选；没有任何合格内容时使用无奖励的回退节点。`pool`残存字段不参与当前候选抽样。

E01浮标、E02饭盒、E03货箱、E04旧货摊与营地每局最多访问1次，商店仍最多2次，冷却均为3航次。未选节点不计访问，查看/读档不重新生成候选。

一般事件一次选择后进入结果，不会在同一访问里反复领取；商店进入交易后可以多次购买，离店后才返回结果。显式属性支付要求支付后至少剩 1。

### 当前普通内容

| 节点 | 当前可执行内容 |
|---|---|
| 漂浮物·缆绳残片 | 1 AP+绳/布各1换木2塑1；或1 AP+木2塑1换铁2绳1；或1 AP+铁/绳/布各1换水食各1；也可离开 |
| 漂浮物·封蜡木箱 | 免费等权木/塑1；或木1+1 AP开箱，70%水食各1、30%塑1；或付SAN10换铁绳各1；也可离开 |
| 漂浮物系列（E01/E03/E04/E05/E06） | 按变体提供免费基础资源、可选交换、设备条件奖励或恢复；每次访问一次选择，成本和目标筏格在选项中公开 |
| 灯火休整地 | 恢复、领取补给、或换取本轮 AP 节奏加成三选一；可离开 |
| 海怪商人 | 进入正式局内商店：3种基础资源＋3种设备，资源各限购2、设备各限购1；支持贝币/尸体支付和单张永久牌出售 |
| 水母转换者 | 付SAN6等权随机基础资源1，或离开；特殊转换/献血/藏品交换禁用 |
| 风暴（E10/E12） | 分段深入探索或指定目标筏格风险；每段只推进当前事件，不推进航次，不重复生产/涌泉 |
| 深潮祭坛 | 已从普通候选池退出，旧数据仅作退役标记 |
| 漂流灯塔 | 免费基础资源或离开；特殊导引不开放 |
| 零星漂浮物（回退） | 普通事件池无合格内容时，无额外收益，继续航行，并记录回退统计 |
| 分支战斗（E11） | 可选普通敌、强敌或避战；战斗奖励由事件覆盖，选项与目标公开 |
| 三种普通战斗 | 啃筏者、水母、蟹；可迎战或离开 |
| 沉没遗迹 | 守卫困难战斗，有败退生命保护；可离开；额外藏品/日记奖励未执行 |
| 层底 Boss | 挑战最后一站，污染型战斗；目前同样存在离开遭遇入口 |

商店每次访问随机生成3种基础资源＋3种设备并保存；每种资源限购2张，共用累计购买数形成1、2、4、8、16、32贝币的原价阶梯。任一资源成功购买后全体资源涨价，设备购买不推进阶梯，新店重置。设备各限1张：灯3、滤水器/土盆4、弓弩/盾架/矛架/捕鱼网/箱子5、发电机6。优惠券先对大于1的原价减1，尸体支付按优惠后价格向上取半。不主动刷新。

永久尸体每张出售2贝币，生存/设备/行动牌每张1贝币；五种基础材料、贝币、临时、战斗、污染和已安装设备不可出售。全部买卖通过真实UID与dispatch校验。藏品货架只显示未开放保留位。

藏品、附魔、献祭、顺流、迷雾和特殊导引的数据存在，不代表对应机制可玩。常驻资源“3换2”已实现，但不是水母节点仍禁用的那套特殊交换。

## 6. 战斗系统

### 行动、牌与材料组合

当前战斗是一个敌人与玩家交替回合；没有四航道部署、敌人多目标阵列、材料弱点倍率或蟹壳减伤机制。

- 固定攻击：1 战斗 AP，基础伤害 1，可重复，不占手牌。
- 固定格挡：1 战斗 AP，获得本回合护盾 1，可重复。
- 射箭：0 AP，伤害 2，使用消耗；由弓弩逐回合提供，可在本场积攒。
- 矛击：1 AP，Ⅰ级矛伤害 3，Ⅱ/Ⅲ级矛伤害 5，使用消耗；矛架只开战提供一次。
- 污染：每张留手在结束回合时扣生命 1；花 2 AP消除，不能直接弃置。

固定攻击/格挡可额外投入一张真实基础资源，总 AP仍为 1，资源会消耗：

| 材料 | 攻击后的总效果（无其他修正） | 格挡后的总效果 |
|---|---|---|
| 无 | 1伤害 | 1盾 |
| 木头 | 1伤害+当回合1盾 | 当回合3盾 |
| 废铁 | 2伤害 | 当回合2盾；遇啃筏者/蟹攻击时反击1伤害 |
| 绳索 | 1伤害；本次敌方攻击伤害−1，不因重复使用叠加 | 1盾+束缚：啃筏者不伤格，水母不施新毒；其他敌人直接伤害−2，最低0 |
| 塑料 | 不支持 | 当回合2盾；敌方行动后剩余最多1盾延续到下一回合，只延续一次 |
| 布条 | 不支持 | 当回合1盾；优先清中毒，其次流血标记；不回血，不清污染牌 |

绳索格挡每回合只能使用一次；对啃筏者/水母取消特殊效果，不同时获得其他敌人的默认减伤。废铁反击准备是布尔值，不会因多次投入废铁叠加反击次数；玩家须先活过本次敌人攻击和后续损失才能反击。

动力强化可附固定攻击或攻击牌；屏障强化可附格挡，或木头攻击这类自身带护盾的攻击。护盾分层存储，优先扣最早到期层；普通盾在敌方行动结束后消失，战后盾全部清除。盾只抵挡直接伤害，不能抵挡中毒、污染、拖延、撤退代价或筏格损伤。

### 敌人

| 敌人 | HP | 每回合直接伤害 | 特性 |
|---|---:|---:|---|
| 啃筏者 | 6 | 1 | 每回合按格ID排序选择首个完好外围格，预告并破损；不是按攻击力换算格数 |
| 胶膜水母 | 7 | 1 | 施加/刷新中毒至当前回合+3 |
| 绝壳蟹 | 9 | 2 | 当前仅直接伤害 |
| 遗迹守卫 | 11 | 2 | 施加/刷新畏惧至当前回合+2 |
| 涌潮之眼 | 18 | 2 | 畏惧；奇数敌方回合结束生成临时污染1张 |

畏惧使玩家攻击伤害−1，最低 1；中毒每个受影响回合扣生命 1。敌人重复施加会刷新期限，因此不能理解为被水母/守卫连续攻击时等固定回合即可自然永久解除。代码有清理流血标记的分支，当前敌人表没有施加流血的敌人。

结束回合的实际顺序：逐张污染扣血并检查生存 → 旧中毒扣血并检查 → 计算束缚/减伤 → 啃筏格损 → 护盾抵消直接伤害并扣血 → 敌方状态与污染生成 → 第7回合起每回合拖延扣血1 → 反击 → 护盾到期/塑料延续 → 回合数+1、战斗AP设为上限、设备发牌/发盾。

### 胜利、撤退与成长

普通胜利：贝币 1、尸体 1、随机基础资源 1、经验 5。困难遗迹：贝币 2、尸体 1、资源 2、经验 5。Boss：贝币 5、尸体 1、资源 2、经验 20。

每 5 经验升一级；4/7/10…级生命上限 +1，不回血；等级除以15余5时基地/战斗AP上限各+1，余10时容量+1。当前普通战胜一次正好升一级。

第2回合起可以撤退：普通扣生命2，战斗狂热免除；教学战斗不能撤退。遗迹撤退或致死时恢复**入场生命数值**并退出，无奖励；消耗过的牌、受损格及其他资源不回滚。由于是恢复入场数值，战内治疗至更高生命后撤退也会回到入场值。

战斗退出清除所有临时牌及污染，返回节点结果文字；确认结果后才计完成节点，基地 AP沿用入场前剩余值。战斗中生命为0一般结束本局，遗迹使用上述保护。

依据：[战斗全部执行分支](../core/battle_rules.gd)、[敌人表](../content/data/enemies.json)、[卡牌表](../content/data/cards.json)。

## 7. 剧情、夜间、局外与保存

剧情模式使用同一套生存、制造、木筏与战斗核心，额外调度固定剧情及夜间，不是另一套战斗规则。

- 第1站到站后给食/水/余温各3；第2站给木1、塑2、滤水器1、弓弩1、食水各2，并要求真实制造→安装→升Ⅱ滤水器才能进事件；第3站给灯1、木3、食水余温各2，并要求赢下啃筏教学战；第4站给食水各2、尸体2并选择同行或独航。
- 独航告别包：土盆2、灯1、木3、食水余温各3；没有分队调查线。
- 第5～14站结束白天进入夜间；第5晚没有主要行动，第6～14晚一次休息或调查。同行路线第5晚接舱门任务，第8/11/14晚先公共剧情，再主行动。夜间不重复航耗，不刷新基地 AP；进入夜间时剩余基地 AP清零。
- 每晚服务阶段可用任意一份基础资源换食物/淡水/余温各1，每晚一次；同行可一次性交绳2换食水余温各2的普通委托。
- 调查成本SAN5，愚者为0；接缝→敲击→深度依次解锁，另有独立记忆调查。线索不能重复领取。
- 第15站同行可选择：三条结构线索+有燃料完好灯+木2绳1封闭（另耗灯燃料1）；接缝线索+至少两格完好+绳2拖离（损一格完好外围格）；或紧急撤离，扣最多2生命且保留至少1。独航走单独出口。
- 结果、尾声、轮末老化和超限整理完成后才到章节停点；本测试第二层未开放，章节本身不发整局点数，主动放弃才结算。

整局结束涌潮点等于已完成日间节点数，死亡/精神崩溃/放弃也按该数结算一次，与千分评分分离。评分四项最高500/250/150/100，分别为航程目标、危机、生存、探索；S/A/B/C/D阈值为900/750/600/400。

局外购买仅非活动局允许：扩建许可、体质（每次HP上限+2，食水精神上限各+5）、开局3币、商店优惠、AP、容量、下局滤水器；科技提供容量、基地AP、精神上限和矛架解锁，带前置关系。下局祝福购买禁用。章节停点仍算活动局，不能直接买成长或开新局。

当前保存是 schema2、内容v11（`godot-flow-v02-11`）、`xorshift32-godot-v1`，需要当前内容指纹一致；v10及更旧内容被拒绝。真实应用成功指令后保存，失败指令回滚状态与随机；规则随机分为起手/节点/奖励/战斗四流。查看与预览用副本，不重掷活动随机。残存迁移函数不代表旧版本仍能通过入口校验。

## 9. 五个系统的关系

航耗形成持续的食水与精神压力，节点和涌泉提供短期补给；制造设备能把有限资源与AP换成稳定产出，但占用筏格。战斗既消耗生命、资源和临时牌，也提供贝币、尸体、基础资源和等级成长；尸体又能支持灯、发电机或商店。筏格破损会同步削弱生产、增益与容量，维修需要和制造/战斗争夺材料。轮末容量则迫使玩家在保留原料、恢复物资、待装设备和货币之间取舍。

这是当前代码已经形成的主要循环；收益是否均衡、某条路线是否稳定生还，需要另做同种子、同开局条件的实际游玩比较，不能由本次静态梳理推出。

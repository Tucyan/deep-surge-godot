# 显示与 UI 大小设置

2026-10-15。本次解决移动端 UI 太小，新增首页右上角“设置”；游戏页沿用已有“设置”入口。没有修改规则、内容或存档版本。

## 已实现

- UI 大小使用滑动条，范围 100%～125%、步进 1%；拖动时显示百分比，松开后应用并保存，避免拖动中重建控件。支持键盘方向键微调并保留焦点。手机首次启动默认 125%，电脑默认 100%。通过 Godot Window.content_scale_factor 调整文字、按钮和卡牌；首页图片按钮同时按比例放大，背景仍铺满。
- 四项生存属性在所有倍率下始终保持一行；阶段/事件区保留手牌上方空间。合成占满整个逻辑画布，固定四列两行、每页最多 8 个配方。翻页仅改变表现状态。
- 游戏页左上菜单和设置中保留“返回首页”。其他面板的导航退出只显示右上角“X”，不再显示“关闭面板”“暂时收起”或“返回首页”。新局步骤、卡牌详情、结算和独立剧情 LOG 的关闭也使用 X；内部配方翻页、日志回看及商店离开等玩法动作保留。
- 手机显示“清晰度”：流畅（场景宽高各 50%）、清晰（75%）、高清（100%）、超高清（125%）。仅调整海面/木筏的 SubViewport，文字、按钮、卡图和首页视频不随清晰度模糊。
- 电脑分辨率使用四档名称：流畅（960×540）、清晰（1280×720）、高清（1920×1080）、超高清（2560×1440）。固定 16:9 窗口模式调整窗口大小；自由比例窗口保留当前大小，以 540/720/1080/1440 的短边上限控制场景精度。全屏使用相同渲染上限，保持显示器原生模式与 UI 清晰度。旧表现配置的 1600×900 回退至“清晰”；不涉及局内存档迁移。
- 显示页新增桌面/手机共用的“帧率上限”：30、60、90、120 FPS、无限制，默认60。选择后即时设置 `Engine.max_fps`，无限制映射为0；使用该选项管理上限并禁用窗口 VSync，避免另一重上限覆盖用户选择。实际帧率仍取决于设备及系统。`fps_limit` 独立保存，旧配置或非法类型/档位回退60，不修改显示器刷新率或游戏规则。
- “显示 / 游戏”分页；原有海面动态、自动理牌、叠牌及放弃本局保留在“游戏”。不新增滚动容器。
- UI 倍率松开滑条后应用，其他选项即时应用。显示与动态设置保存到 `user://display-settings.cfg`；手牌设置仍存原独立配置。关闭设置、调整 UI 和画质不改变 AP、物资、剧情游标、种子或随机流。

## 实现边界

`presentation/display_settings.gd` 管理平台判断、配置读写、窗口显示和场景尺寸计算；`presentation/settings_panel.gd` 管理设置控件；`flow_app.gd` 组合并在尺寸变化时更新场景视口。GameSession 不持有设置或界面对象。

场景显示通过全屏 `TextureRect` 将独立 `SubViewport` 的渲染纹理映射到完整逻辑画面。渲染像素数只控制清晰度，不控制纹理在屏幕上的占位尺寸；切换 UI 倍率及清晰度后木筏保持原屏幕位置。

2026-10-17 新增“画面比例”：默认 16:9（保留黑边）；自由比例使用 `Window.CONTENT_SCALE_ASPECT_EXPAND` 扩展逻辑画布，跟随横屏窗口/屏幕，适配范围为 3:2～21:9。按用户后续澄清，游戏保持横屏，不提供竖屏布局；先前的 2:3 描述按横屏 3:2 理解。切换比例不强制改变窗口大小，清晰度只降低独立场景视口精度，文字、图片、视频保持清晰。偏好 `free_aspect` 保存到独立显示配置，非法或缺失值使用固定比例。125% UI 缩放保持可用。

首页使用最新灯塔星海视频、透明 Logo 和 v3 连续轨道边框；视频保持原始 21:9 比例并覆盖裁切，不拉伸；按钮向右锚定，Logo 位于左侧。边框装饰统一等比缩放，四条轨道沿对应轴延展。参考截图只作构图参考，不作为背景覆盖交互。

## v16视角偏好

设置→游戏偏好新增“视角锁定”，默认关闭，独立持久化`view_locked`。关闭时鼠标左键转动/滚轮缩放，触摸单指转动/双指缩放；开启只禁止手动视角输入，不停用自动构图。主界面及设置均提供视角复位，锁定时仍能复位。与GameSession保存、AP和随机流分离。详见[螺旋木筏与视角](spiral-raft-and-camera.md)。

中键平移与R复位补充：视角锁定同时阻止中键水平平移；主菜单/设置复位与R共用约0.45秒平滑过渡，重置方向、缩放和水平位置。模态设置打开时R不穿透场景。仍为本地表现，不修改内容版本或局内保存。

## 视角按键自定义（当前）

设置→游戏偏好新增旋转/平移鼠标绑定（左/右/中键，冲突时互换）与复位键录入（点击后按新键，Esc取消），并提供恢复默认。默认右键旋转、左键水平平移、R平滑复位，滚轮缩放保持。绑定分别存为camera_orbit_button/camera_pan_button/camera_reset_key，缺失或非法配置使用默认；只写独立表现设置，GameSession状态和当前内容版本不变。按钮提示跟随当前绑定更新。

自由视角水平平移现限制为相对默认自动构图位置的3米半径，斜向同样受限，反向拖动立即回移。此为表现层固定限制，不增加偏好字段，锁定/按键配置和平滑复位保持。

本次横屏适配与首页更新见[验证记录](../evidence/title-v3-display-verification.md)。

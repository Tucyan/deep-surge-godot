# 出身规则 v1

> 历史版本：囤积癖、战斗狂、设备匠已在v25更新，当前以[出身规则v2](origins-v2.md)为准。本页保留v24规则与其他五种未变更出身的依据。

2026-10-18，Godot 内容版本 `godot-flow-v02-24`。八种出身已接入；拾荒者仅保留禁用项。数值来自[设计草案](design/origins-redesign-v1-proposal.md)，属于试测参数，没有宣称出身强度已均衡。

## 可用效果

| 内部ID / 名称 | 实际规则 |
|---|---|
| zealot / 战斗狂 | 每个玩家回合获得1战意；攻击、格挡、矛击、清污染优先消耗战意，不能打捞，回合不累计。胜利按战后玩家等级额外获得基础材料：1～3级1张、4～6级2张、7级起3张。撤退仍扣2生命 |
| engineer / 设备匠 | 本局首次直接制造滤水器、土盆各附带1生产进度；安装时转入设备，不立即生产。每航次首次成功升级返1基地AP；原子制作升级仍需先支付原价，完成后返1，不附赠生产进度 |
| hoarder / 囤积癖 | 基础容量+3；最高等级的一台完好已安装箱子额外+1/2/3容量，不逐箱累加；箱子原收益照常 |
| strong / 强壮之人 | 初始生命及上限+4；每航次首张有效包扎包额外恢复1生命，基地/战斗共用次数。满生命使用不占次数。取消旧食水上限加成 |
| fool / 愚者 | 每次实际移动SAN航耗为10，燃灯与否均适用；每航次首次有效侦察SAN4，之后8，支付后至少留1。取消原通用精神损失减免，不减免事件支付 |
| skeptic / 无魔之人 | 明确免疫敌方中毒和畏惧，不自动免疫未来状态；每场首次主动清除污染0AP，后续收费。仍会生成污染且留手扣血，直接伤害与筏格损伤不免疫 |
| restless / 行动派 | 基地与普通战斗AP上限各+1。保留原效果，只改展示名，内部ID不变 |
| merchant / 海上掮客 | 开局3贝币，可与局外开局币叠加。每店首次成功购设备，券后首店再减1币、第二家起减2币，最低1币；材料阶梯、出售和限购不变 |
| scavenger / 拾荒者 · 暂未开放 | 选择列表禁用，直接建局/Agent请求与恢复校验均拒绝；未实现定向打捞 |

战斗狂额外材料是木头/废铁/塑料/绳索/布条等权有放回抽取的永久牌。先抽原基础掉落，结算经验和通用升级，再按战后等级抽出身额外牌；原奖励不被覆盖。撤退、保护败退、离开和死亡不发额外奖励。超限仍在航行轮末整理，界面预览或查看结果不能重复领奖。

设备匠只对直接制造的首件对应设备生效，买入、局外发放和原子制造升级不触发调试；原子制造升级也不消耗该类首次直接制造资格。携带进度的设备牌用于合并时沿用原规则，不向目标转移供体进度。破损仍暂停生产。

## 次数、保存与事务

`state.origin_state` 为纯JSON数据：

```text
{
  heal_voyage: 0,     # 上次触发强壮治疗的航次
  scout_voyage: 0,    # 上次使用愚者侦察优惠的航次
  upgrade_voyage: 0,  # 上次触发设备匠返AP的航次
  tuned: [],         # 已发首次调试的 filter / planter
  shops: []          # 海上掮客按实际进入顺序记录的不同 visit_id
}
```

航次额度用已消费航次与当前航次比较；进入战斗、结束回合、开关面板与读档都不刷新。无魔之人另使用 `battle.origin_clean_used`；战斗狂使用 `battle.origin_ap`，正常回合刷新至1。携带调试进度的牌含 `origin_progress: 1`。

所有触发均在现有 `dispatch` 事务内发生，失败回滚状态、随机和资格；只读报价/预览在副本执行。读取恢复校验计数、类型、身份归属和携带进度。新版沿用 schema2 与原随机算法，但内容版本升24，拒绝v23及更旧玩法档，不自动迁移或重置旧文件。独立剧情档不改版本。

新手教程继续固定教学出身、起手和原教学体质，**不启用新版出身触发**；不把教学战斗、买卖或设备进度改成新出身规则。

## 核心与界面接入

- `core/origin_rules.gd`：元数据/启用状态、资格、实际费用、首次调试、治疗和折扣。
- `game_session.gd`：建局、版本、公开投影；`inventory.gd` 计算完好箱子容量。
- `battle_rules.gd`：统一 `action_payment/card_payment`，支付普通AP/战意和胜利材料。`action_query.gd` 使用动态费用识别免费操作，自动推进复用该查询。
- `run_rules.gd`：制造、安装、升级、恢复与航耗；`environment_rules.gd` 生成真实侦察报价；`shop_rules.gd` 同一报价用于显示与扣款。
- 新局页显示出身名称和独立说明，拾荒者禁用；战斗HUD分开显示普通AP和战意，预览/手牌按钮/快捷出牌使用同一费用判断；导航显示SAN4或8。
- 只读手牌投影可含 `ap_quote`，固定动作可含 `origin_ap`，Agent沿用现有命令即可使用，不新增绕过规则的专用指令。

# 《明日方舟》黑流树海：“不期而遇”事件清单（精简版）

根据完整版本筛选，删除原编号 **6—10、19—24** 的11个事件，保留13个事件并重新连续编号。多分支事件仍展开详细选项与结果；游戏内叙事文本适当概括。以下分类是便于机制分析的**非官方分类**，同一事件可能同时属于多种类型。

资料来源：
- PRTS：https://prts.wiki/w/沉沦者的黑流树海/事件一览
- BWiki：https://wiki.biligame.com/arknights/沉沦者的黑流树海/调查记录

## 分类总览

| 自定义类型 | 核心玩法 | 保留的代表事件 |
|---|---|---|
| 免费资源/固定奖励 | 无需成本，直接在几种收益之间抉择 | 桑尼的邀请、色味不同源 |
| 资源交换 | 消耗源石锭、生命、行动力或材料换取收益 | 货从口出、沉重的契约、敲动杠杆、愈创之心 |
| 随机/赌博 | 承担不确定风险，结果可能为奖励、回血、空奖或战斗 | 被歌颂的影子、湖中仙女、洞中宝 |
| 战斗抉择 | 主动进入战斗、升级难度或避战 | 思乡心切、划算买卖、鸭托邦、传奇团伙 |
| 连续递进 | 可选择继续或提前结束，形成多轮决策 | 被歌颂的影子、湖中仙女、洞中宝 |
| 条件联动/地图影响 | 特定物品解锁选项，或改变后续区域流程 | 愈创之心 |

## 一、13个“不期而遇”事件（选项 → 结果）

### 01 桑尼的邀请｜固定资源
- **帮它梳理绒毛** → 获得3希望。
- **唱一首摇篮曲** → 获得10源石锭。

### 02 色味不同源｜生存资源
- **拿走看上去像是苹果的食物** → 目标生命值上限+3。
- **拿走看上去像是鱼的食物** → 获得5护盾。
- **我不饿** → 离开，无奖励。
- 特点：一局内有概率重复出现。

### 03 货从口出｜付费换零件
- **想要一个能节省力气的** → 消耗4源石锭，获得1件随机加工品。
- **想要一个可以保值的** → 消耗4源石锭，获得1件随机概念体。
- **想要一个树海特色纪念品** → 消耗4源石锭，获得1件随机自然物。
- **没什么想买的** → 离开。
- 特点：一局内有概率重复出现。

### 04 沉重的契约｜资源换行动力
- **上去帮个小忙** → 获得2行动力。
- **推翻石磨** → 消耗当前目标生命值的一半，获得5行动力。
- **不关我的事** → 离开。

### 05 敲动杠杆｜付费收藏品
- **敲一次** → 消耗4源石锭，获得1件随机收藏品。
- **敲三次** → 消耗10源石锭，获得3件随机收藏品。
- **不感兴趣** → 离开。
- 特点：一局内有概率重复出现。

### 06 被歌颂的影子｜8轮递进挑战
- 事件最多进行**8轮选择**。每轮都可以选择**继续**或**离开**：选择“继续”消耗该轮所需的目标生命，并获得对应的随机或固定结果，随后进入下一轮；选择“离开”则立即结束事件。
- **继续不代表一定亏血**：部分轮次的随机结果包含**回复目标生命**，因此可能回血；具体数值及其他奖励见下表。

| 轮次 | 选择「继续」的成本 | 本轮获得 |
|---|---|---|
| 第1轮（缺眼睛） | 1目标生命 | 随机：4源石锭 / 回复1目标生命 |
| 第2轮（缺嘴巴） | 1目标生命 | 随机：2希望 / 回复1目标生命 |
| 第3轮（缺左前腿） | 2目标生命 | 随机：1件自然物 / 回复2目标生命 |
| 第4轮（缺右前腿） | 2目标生命 | 随机：1件加工品 / 12源石锭 / 回复2目标生命 |
| 第5轮（缺左后腿） | 2目标生命 | 随机：1件收藏品 / 回复5目标生命 |
| 第6轮（缺右后腿） | 3目标生命 | 随机：8希望 / 可携带干员+1 / 回复3目标生命 |
| 第7轮（缺肚子） | 3目标生命 | 固定：3件随机收藏品 |
| 第8轮（七条狗） | 3目标生命 | 通常：收藏品「犬植浆」；已有相关「植浆」/「犬植浆」时改为1行动力 |

- 第8轮的具体条件：进入本事件前既没有「植浆」，又没有从该事件获得的「犬植浆」，则固定得到「犬植浆」；否则为1行动力。来源页面提示此判定有条件限制。

### 07 愈创之心｜行动力与循环区域
- **紧紧拥抱愈创木** → 消耗3行动力，获得收藏品「追忆」。
- **让这里有一个秋千** → 消耗随机2件加工品，获得「追忆」。
- **比对像素小猫和树干刻痕**（需源私钥） → 消耗「源私钥」，获得「追忆」。
- **检测此地有无危险**（需笼控器） → 获得5行动力。
- **闭上眼感受宁静** → 获得1行动力。
- 「追忆」效果：进入下一区域时改为重新进入当前区域，之后失效。

### 08 思乡心切｜可选特殊战斗
- **赶跑它** → 进入特殊战斗「陌生旅伴」。
- **安慰它** → 离开，无战斗。

### 09 划算买卖｜可选特殊战斗
- **让它闭嘴** → 进入特殊战斗「安保措施」。
- **装没听到** → 离开，无战斗。

### 10 鸭托邦｜普通/紧急版分支
- **呛一句** → 进入特殊战斗「开业剪彩」（普通）。
- **故意挑事** → 进入「开业剪彩」（紧急版，更难）。
- **兴趣缺缺** → 离开。

### 11 传奇团伙｜战斗或财产损失
- **凭什么？** → 进入特殊战斗「合伙人会议」（普通）。
- **扎穿货车车胎** → 进入「合伙人会议」（紧急版）。
- **果断求饶**（持有超过50源石锭时可出现） → 交出一半源石锭逃跑。
- 注意：部分选择在选择后还会出现确认战斗的剧情节点。

### 12 湖中仙女｜多次付费的随机终局
- **上前看看** → 进入与仙女交涉的第二层分支。
- **不理会她** → 离开。
- 交涉后，**拿出诚意** → 支付1源石锭；连续支付会看到磁石、破手表，后续再次支付随机分化为：获得1件珍贵收藏品，或与「湖中魇」进行紧急特殊战斗。
- 每轮可选 **休想骗我** → 识破仙女并触发「湖中魇」普通特殊战斗；或 **离开** → 不再承担风险。
- 注：具体分支按Wiki的连续付款树状流程简化表述；不可将随机奖励理解成必得。

### 13 洞中宝｜可循环随机抽取
- **树洞里肯定有好东西／掏一下** → 随机发生：获得5源石锭；获得1件收藏品；空洞未获奖励；树洞咬人，进入艰难战斗（随机抽取下一层的普通作战）。
- 某些随机结果之后可选 **一定是错觉／继续掏** → 再抽一次；或 **太诡异了** → 结束。
- **离开** → 不冒险，无奖励。
- 特点：有概率在一局内于「误入奇境」内外各出现一次。

## 三、机制总结（仅针对本版保留的13个事件）

1. **基础奖励分支**：在希望、源石锭、生命上限或护盾等收益之间选择。
2. **成本交换分支**：支付源石锭、生命、行动力、零件或特殊道具，获取新资源与能力。
3. **战斗与避战**：主动挑战特定敌人，也可能选择更高难度的紧急战斗。
4. **多轮风险管理**：「被歌颂的影子」最多8轮，每轮可继续或离开；继续可能获得资源，**也可能回血**；「湖中仙女」「洞中宝」同样允许在部分阶段止损。
5. **条件与区域变化**：「愈创之心」存在特定道具选项，并可能影响进入下一区域的方式。

**说明**：事件选择与结果依据上述Wiki记录整理；概率、奖励池及未披露的隐藏权重不作额外推定。

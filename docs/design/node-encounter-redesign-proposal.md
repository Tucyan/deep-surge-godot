# 节点事件重设计与平衡讨论稿

2026-10-16；依据当前 Godot 代码 `godot-flow-v02-9`。**状态：提案，等待讨论，不是已经采用或实现的规则。** 本轮只编写方案；所有新数值都是待实际游玩验证的初始参数。

参考材料为用户提供的[《黑流树海》不期而遇精简清单](references/arknights-encounters-user-reference.md)，已原样保存以便追溯。本轮依据该材料分析其选择结构，没有独立核验所列 Wiki 的现行奖励或隐藏概率，也不照搬原作文本与数值。

## 1. 结论：不应把资源牌设为普遍的收益门票

节点可以免费给收益。玩家来到这里已经占用一轮航行、承受食水和精神航耗，并放弃其他目的地。这些是玩家实际承担的成本，不能忽略后再要求所有收益都额外付材料。

但所有候选都有共同航耗，所以也不能简单要求“每个节点都补回30食、30水、15精神”。那会使设备失去长期价值。应比较同一轮不同目的地的机会成本，让节点分别解决短期缺口、补充制造资源、提供成长机会或允许主动冒险。

**建议：基础收益一般可直接获得，稀缺或额外收益允许付费，风险由玩家主动选择。** 资源支付主要承担三个职责：

1. 定向转换：把暂时多余的材料换成当前缺的材料，奖励在确定性上有价值。
2. 加码收益：免费拿一份，或支付一种代价换更多/更特殊的收益；两者互斥，不默认先领免费再加购。
3. 构筑联动：已安装设备、燃料或已有物资解锁更好的处理方式。条件不必等于消耗，例如有捕捞网即可使用它，不必每次销毁一张绳索。

应减少“同时交多种材料＋AP＋属性损失＋筏格损伤”的普通选项。若存在复合成本，应是明确的大额交易，并把最坏损失展示出来。困难战斗和高风险事件可以只提供无奖励退出，不必给所有出口附送资源。

## 2. 当前代码中的具体问题

依据：[当前机制梳理](../current-game-mechanics.md)、[正式节点表](../../content/data/nodes.json)、[通用节点执行](../../core/run_rules.gd)。

| 当前设计 | 实际问题 | 调整方向 |

| 缆绳残片：绳1、布1、AP1→木2、塑1 | 两类材料门槛，净增1张；无材料者只能离开 | 提供免费定向材料选择，AP用于额外打捞 |
| 金属箱：木2、塑1、AP1→铁2、绳1 | 三张换三张还付AP；价值主要是调换种类 | 将定向交换做成清晰的专门事件 |
| 补给箱：铁、绳、布各1、AP1→水食各1 | 缺食水的人还要同时持有三类制造材料 | 至少有一条无材料门槛的生存补给 |
| 风暴深入打捞：木绳各1、AP1→木1铁2并伤格 | 还要承担维修/停产/失去设备风险，收益未补偿全部成本 | 风险分支提高净收益，或去掉材料门票 |
| 营地：HP6、食水SAN各40、后两轮AP+1 | 免费恢复与发展集中在一个选项，容易压过其他事件 | 拆成恢复、储备、后续行动三选一 |
| 遗失货袋、祭坛 | 当前唯一获益功能被禁用，实际只剩离开 | 换成当前系统能够兑现的事件 |
| 部分设备只有经济收益 | 玩家不容易在事件中感受到设备的用途 | 少量设备条件分支，提供处理问题的新方式 |
| 一次点击就结束几乎所有事件 | 缺少“继续还是收手”的过程 | 增加一类有限轮次的深入探索 |

按变体展开，当前共有10个非战斗事件配置，其中遗失货袋与祭坛没有可执行的获益选项。这个统计不包含独立商店交易入口，也不能当作实际遇到它们的概率。

### 两个风险收益例子

- 当前风暴“系绳深入打捞”即时净张数为+1。假设损伤的是完好格，之后用木头1和AP1立即修复，整套流程净牌数为0、总花费2 AP；最终完成的是绳1和木1换铁2。两次常驻打捞则只花2 AP获得两张随机基础资源。定向废铁有价值，但旧风暴并未提供充足的风险溢价。
- 当前沉底货舱：65%铁2、35%铁1并伤格，先付绳1和AP1。仍按完好格、木头立即修复计算，期望得铁1.65，减绳1和期望维修木0.35，净牌仅0.30，期望AP为1.35；尚未计入设备停用损失。若击中原本破损格，当前代码还可能直接脱落，损失更大。

张数只用于暴露问题，不是统一价值标尺。缺水时的一张淡水、缺塑料时的确定塑料、接近容量上限时的多张杂料，价值各不相同。

## 4. 统一设计规则与价值尺度

- 通常2～3个有效选择，另可退出；恢复/材料取向需不同，避免只做同种奖励的小中大。
- 每次访问通常只能领取一个分支。只有E10明确允许连续领取，不可在返回界面后重置。
- 免费收益建议为确定基础资源2张、或生存牌1张、或一次明确的小服务，按事件定位选择，不能把几项常态叠送。
- 额外花1 AP的打捞应明显优于常驻“1 AP随机1张”；例如在免费1张的基础上，放弃免费分支并用1 AP拿3张。
- 普通材料门槛优先一种材料1张。要求两种以上，应该对应可见设备或明显更高的奖励。
- 属性是独立成本。基础HP只有12，HP2已是六分之一生命，不能照搬参考中的一半生命或八轮持续扣血。
- 主动支付HP/SAN必须至少保留1。随机风险可以致死时，应在确认前明示最大伤害和死亡可能。
- 伤格必须说明目标及是“完好→破损”还是“破损→脱落”；新事件不把失去带设备筏格藏在含糊的“损伤一格”背后。
- 既有永久设备应继续承担持续供给，节点主要补短期缺口。基础资源、物资牌、设备牌、货币、属性和AP分开记录，不换成一个未经验证的总分。

长期供需用于检查奖励是否过量：一张食物/水提供40，对应每次移动消耗30，稳定需求约为每种每轮0.75张。Ⅰ级食水设备平均每轮提供20点，小于30；Ⅱ级每轮40点才足以覆盖长期消耗。节点一次给食水各1能缓冲约1.33次移动，但不等于建立长期供应。

以12次航行、随机7张开局计算，现有起手+涌泉共51张基础资源，木头期望19张、其余每类8张；这不包含生产、事件、战斗、打捞，也未扣制造/燃料/弃置。免费事件增加的是选择空间，仍需限制重复频率和容量压力。

## 5. 十二个事件的完整草案

下列ID用于讨论与后续实现映射。所有“随机基础资源”均从五种基础资源等权有放回抽取；“免费”是无额外AP/材料/属性支付，不豁免此次移动航耗。除E10外分支互斥。

### E01 浮标上的便笺｜免费定向资源

便笺上写着“留一些给下一个人”，三捆物资用不同颜色的绳子绑好。

| 选择 | 支付 | 获得 |
|---|---|---|
| 取走浮木捆 | 无 | 木头2 |
| 取走修造袋 | 无 | 废铁1、绳索1 |
| 取走密封包 | 无 | 塑料1、布条1 |

作用：在燃料、战斗、制造之间选用途，不考验玩家是否恰好持有门票。每局可完成两次，两次之间至少间隔2个其他节点；首次即可出现。

### E02 尚温的饭盒｜免费生存抉择

浮箱里只有三份完好的东西，你只能带走其中一份。

| 选择 | 支付 | 获得 |
|---|---|---|
| 带走封口饭盒 | 无 | 食物1 |
| 带走淡水瓶 | 无 | 淡水1 |
| 留下听完录音 | 无 | 灯火余温1 |

作用：急救方向由玩家判断，物资可以留到后续使用。每局最多两次，至少间隔2个其他节点；首次即可出现。

### E03 绳端的货箱｜AP与设备条件

浮绳末端连着几只半沉货箱，一小块木料已经漂到筏边。

| 选择 | 支付/条件 | 获得 |
|---|---|---|
| 收下筏边木料 | 无 | 木头1 |
| 花时间逐个拖上来 | AP1 | 木头1、废铁1、塑料1 |
| 用捕捞网兜住货箱 | 完好已安装捕捞网；不消耗设备或材料 | 木头1、废铁1、塑料1 |

第三项以设备节省一次AP，不额外叠加前三张奖励；捕捞网等级不改变此事件收益。每局最多两次，至少间隔2个其他节点。

### E04 雾里的旧货摊｜低门槛定向交换

摊主愿意把手边的散件换成你带来的另一种材料。

| 选择 | 支付 | 获得 |
|---|---|---|
| 拿走免费边角料 | 无 | 木头1 |
| 挑两份有用的散件 | 自选基础资源1张；不收尸体 | 自选另一种基础资源2张；0 AP |

输入与输出类型不能相同，一次访问仅交易一次。核心价值为确定补缺；不能一换二后继续循环。每局最多两次，至少间隔2个其他节点。

### E05 封蜡死箱｜有保底的单次风险

箱盖保存完好，箱底却偶尔传来撞击。你能先拆下外层木条，也可以打开整箱。

| 选择 | 支付 | 获得/风险 |
|---|---|---|
| 只拆外层木条 | 无 | 木头1，结束 |
| 撬开箱盖 | AP1；无材料门票 | 70%食物1+淡水1；30%废铁1并损HP1 |

没有额外暗中战斗或设备损失。HP1时风险确认明确写“失败会死亡”。期望物资1.70张、HP损失0.30，但食水与废铁用途不同，不能只按张数比较。每局最多一次，第3站起出现。

### E06 船底的回声｜精神换确定材料

敲击声指出沉在船底的金属，但听得越久，越难分辨它来自哪里。

| 选择 | 支付 | 获得 |
|---|---|---|
| 堵住耳朵，等待声音远去 | 无 | SAN+8，直接恢复 |
| 听清它指出的位置 | SAN6，支付后至少1；不花AP | 废铁1、绳索1 |

相对安全分支，选择材料意味着少8点恢复并额外花6点SAN，实际机会差为14点精神。属于自愿支付，沿用当前规则，不被愚者的通用负面效果减免抵消。每局最多一次，第3站起出现。

### E07 漂流者的午餐｜免费救急与资源加码

对方愿意分享一份午餐；如果你能留下木料修炉架，还能多分一瓶水。

| 选择 | 支付 | 获得 |
|---|---|---|
| 接受一份食物 | 无 | 食物1 |
| 请求一瓶淡水 | 无 | 淡水1 |
| 留下修炉的木料 | 木头1，0 AP | 食物1、淡水1 |

资源成本只购买额外的一份物资，不决定有没有救急机会。每局最多一次；首次即可出现。

### E08 筏匠的残台｜维修与储备

工作台还留着工具和一些散件，潮水只允许你完成一项事情。

| 选择 | 支付/条件 | 获得 |
|---|---|---|
| 请他补好筏格 | 自选一个破损功能格；0材料、0 AP | 恢复完好，保留设备及进度 |
| 带走剩余散件 | 无 | 废铁1、绳索1 |

不能修脱落格，也不免费升级设备。没有破损格时隐藏维修选项，仍有散件可拿。每局最多一次，第3站起出现。

### E09 搁浅的绞盘｜生命换额外行动

借绞盘整理货物能省下时间；若冒险把卡住的转轴扳开，还能更快完成工作。

| 选择 | 支付 | 获得 |
|---|---|---|
| 借用仍能转动的部分 | 无 | 本轮当前基地AP+1 |
| 强行扳开转轴 | HP2，支付后至少1 | 本轮当前基地AP+3 |

相对免费分支，HP2购买额外2 AP。允许当前AP暂时超过基础上限，轮末清零，下一轮按原上限刷新；不提高永久上限，也不影响战斗AP。每局最多一次，第4站起出现。

### E10 海面下的货舱｜三段深入、随时收手

第一只货袋已浮出水面，另外两层还藏在船舱深处。

| 阶段 | 决策与支付 | 结果 |
|---|---|---|
| 1，水面货袋 | 免费收下 | 随机基础资源1；然后选离开或继续 |
| 2，舱门 | 继续付AP1 | 75%随机基础资源3并开放第3段；25%损HP1，本段无资源，立即结束 |
| 3，底舱 | 再继续付AP1 | 55%随机基础资源4；45%损HP2，本段无资源；两种结果都结束 |

每次继续都可事先查看本段概率、AP和最大伤害。随时离开保留已经得到的资源，失败也不没收前面奖励。HP低于或等于潜在伤害时继续确认明确提示死亡风险。没有AP仍可领取第一袋并离开。

若资源与生命允许，始终选择继续：期望基础资源为`1+0.75×3+0.75×0.55×4=4.90`；期望AP消耗`1+0.75=1.75`；期望HP损失`0.25×1+0.75×0.45×2=0.925`。最多获得8张牌。作为粗略参照，E01免费2张再投入同样期望AP打捞为3.75张；深入路线多约1.15张，但承担生命风险、随机种类与容量负担。这里是事件树算术，不是整局胜率预测，也未把不同资源等同为同一价值。

每局最多一次，第5站起出现。关闭面板后恢复原段落；已发生结果保存，退出不能重进重抽。

### E11 哨声与甲壳｜普通战斗、强敌、避战

一群甲壳生物占着浮台。边缘的个体容易引走，浮台中央那只守着更多物资。

| 选择 | 战斗与支付 | 胜利奖励总量 |
|---|---|---|
| 引走边缘的蟹 | 普通蟹：HP9、伤害2；沿用当前行为 | 贝币2、尸体1、随机基础资源2、经验5 |
| 挑战中央的巨蟹 | 提案强敌：HP12、伤害2；相同行为 | 贝币3、尸体1、随机基础资源3、经验5 |
| 熄灯绕过浮台 | 不进入战斗 | 无奖励 |

普通选项第4站起，强敌第7站起开放；整个事件每局最多一次。强敌增加的是持久战压力，不声称对所有构筑都同等更难。没有遗迹生命保护，撤退沿用普通规则；胜利奖励为表内总量，不能再叠一份默认奖励。战斗中不能改挑战难度，败退不发挑战奖励。

### E12 浪中的吊架｜可预见的筏格代价

沉重吊架即将入水。你可以让一块空甲板承受冲击，也可以用绳索分批卸货。

| 选择 | 支付/条件 | 获得 |
|---|---|---|
| 沿浪缝驶离 | 无 | 下一次移动食水各少扣5；不叠加多次标记 |
| 用空甲板接住吊架 | 自选完好、无设备外围格；至少还有另一格完好功能格；该格变破损 | 废铁3、木头1、塑料1；0 AP |
| 用绳索分批卸货 | 绳索1，0 AP | 废铁2、木头1；不伤格 |

格损是明确支付，确认前高亮目标，只把完好空格变破损，不随机伤设备，也不直接脱落。若之后用木头修复，接吊架分支净得4张基础资源、付维修AP1；玩家可权衡是否立即修复。没有合法空格时关闭该分支，其他分支仍可选。每局最多一次，第5站起出现。

## 6. 专门的营地、商店与原有战斗

### 营地：从全都给变为选择方向

三个分支均免费、互斥：

| 分支 | 提案效果 | 适合的处境 |
|---|---|---|
| 包扎与休息 | HP+4，食水各+20，SAN+20，直接恢复 | 已受伤、多项状态偏低 |
| 整理随行口粮 | 食物1、淡水1 | 需要可储存补给，或食水缺口大 |
| 校准航行节奏 | SAN+25，后续两轮基地AP上限+1 | 生存暂稳，希望建设发展 |

保留“安全休整地”的价值，但不再同时领取全部恢复、可储存物资和发展加成。每局最多完成两次，两次间至少隔2个其他节点；上次在N站，最早N+3再次进入。末站固定终点不投放营地。

### 商店：给战斗收益一个可用出口

既有设备价保留作为首轮对照：灯2、滤水器3、土盆3、弓弩4贝币。提议增售食物、淡水、包扎包，各2贝币，分别每次访问最多买1。设备也各限购1张/次；保留尸体抵价与优惠券规则。一次访问可买多个不同商品，免费听故事恢复SAN5则结束该次访问，不能买完再回头领故事。

食水不卖1币：否则一场普通战斗的2币恰好直接购买食水各1，再叠全部战利品，可能使战斗路线过早覆盖双项航耗。2币是初始检验值，不是确定的等价汇率。

商店只投放已有实际效果的商品；藏品不占货架。每局最多完成两次，至少间隔2个其他节点。无钱仍可听故事，但商店不能充当“本轮保证有实用补给”的唯一候选。

### 普通战斗与遗迹

第一轮节点试测保留当前普通战斗、遗迹、Boss的敌人数值和基础奖励，以便分辨节点调整带来的影响。挑战末站Boss和剧情第15站终点继续固定。E11只是增加可比较的战斗分支，不替代全部战斗节点。遗迹说明应只承诺真实发放的奖励，暂不写藏品/日记收益。

## 7. 投放、候选与重复频率

事件增加后不能把全部事件ID等概率塞进池；否则增加文本数量就会悄悄改变战斗、营地和商店占比。建议先抽类别，再抽合格事件；下表是**原始抽样权重提案，不是玩家最终访问比例**：

| 类别 | 权重 | 内容 |
|---|---:|---|
| 补给/打捞 | 25 | E01、E02、E03、E05 |
| 交易/分享 | 10 | E04、E07 |
| 状态/服务 | 15 | E06、E08、E09 |
| 主动风险 | 10 | E10、E12 |
| 战斗/遗迹 | 20 | 现有普通战斗、遗迹、E11 |
| 营地 | 10 | 三种休整方向 |
| 商店 | 10 | 有限货架 |

一个候选集仍最多3项：先从合格的补给/服务/营地中抽一项保证无强制战斗、无资源门票的有效收益，再按权重补足其余项。候选事件不重复，同屏营地和商店各不超过一个；不是保证必有战斗。未来精确权重需连同此保底规则一起统计，不能把25直接当成实际25%访问率。

“有效收益”按当前可见状态过滤：例如满SAN时只有精神恢复的事件不能独自承担保底，E08有确定材料则仍有效；有免费资源但需要之后弃牌不判为无效。保底只负责一项，另外两项可以展示尚缺条件的机会，并提前显示条件。

前两次普通导航至少有一个可免费取食物或水的候选（E02/E07），不保证自动发放，也不保证一站同时给食水。剧情固定教学1～4站优先，不插入这条保底；5～14站按普通候选处理。玩家仍可能在到达事件前因航耗死亡，节点到站后的奖励不能回溯救命，导航需展示抵达后属性。

重复频率按前述每事件上限执行，稀有风险/成长事件每局一次；E01～E04中允许重复的事件、营地、商店均至少隔2个其他节点。可沿用当前访问次数降权，避免相邻候选总是相似。

当上限/时间条件使某类没有合格事件时，将它的权重在其他合格类别中重新归一，不能转成空白节点。全部普通事件耗尽时可退到公开的“零星漂浮物”：免费随机基础资源1，或离开；记录回退次数以检查投放配置，不能用回退掩盖频繁空池。

挑战与剧情先共享上述事件数值，分别报告表现：剧情已有教学包和夜间大量恢复，不能把其高生还率归因于事件平衡。若需分模式调参，应先从投放频率入手，并明确公开差异。

## 9. 实现边界与建议落地顺序

本稿完整方案需要新增少量通用能力，不能声称改JSON就能全部完成。

**第一批，先检验免费收益与营地拆分：** E01、E02、E03前两项、E05、E06、E07及营地，主要复用现有给牌、改属性、AP成本、材料支付和概率结果；同时替换或移出遗失货袋、祭坛等无收益占位。暂保留当前普通候选生成和商店，单独观察经济变化；不把完整投放承诺套到这一批。明确提示E05潜在致死，不通过隐藏条件保证永不死亡。

**第二批，补齐事件类型与投放：** E04自选输入/输出；E08目标修复；E09本轮AP奖励；E10分段状态；E11选项开战、敌人变体与总奖励覆盖；E12目标格损支付；E03设备条件；商店限购和分类投放/次数限制。实现后才算完整采用本稿。

这些能力放入通用规则入口与ActionQuery，UI只选择和确认；不在Agent适配器按事件ID特殊处理。特别需要处理：

- 设备条件检查完好、已安装、必要时有燃料；“需要持有”与“会消耗”分别展示。
- E04消耗指定永久基础资源UID，不能拿尸体或临时战斗牌充当材料。
- E08/E12传当前合法目标格ID，失效目标和旧revision原子回滚。
- E09只加当前基地AP，不改player上限，额外AP不结转。
- E10保存段落、已发奖励、已抽结果及退出状态；一次访问只计一个日间节点，每次继续不推进航次、不生产、不补涌泉。
- E11预览双方数据和全部奖励；胜利只发一次，撤退不误计胜利，事件战斗不触发剧情教学限制。
- 接受风险之前可以离开；新可选事件的安全退出不应被统计为“挑战失败”。危机统计在接受挑战后建立，区分成功、主动停止、失败，避免评分逼玩家赌博。当前统计存在按storm/monster判定的分支，必须一起评估，不能只改选项名。
- 随机继续用可恢复流；预览/取消不改变活动随机，打开界面不重抽。代码与数据版本变化后重新开局试测，按当前开发政策拒绝旧版本存档，不开发迁移层。

## 10. 如何判断方案是否更合理

本轮只完成静态分析与事件树算术，未修改代码、未进行新方案实际游玩，不能宣称“已经平衡”。确认方案后，先用Agent中间层作同种子、同出身、同起手的基线对比，再做图形操作检查。

建议先采用12个种子（0、1、2、3、7、11、17、22、31、42、73、99），分挑战/剧情，并覆盖强壮、愚者、多动症、囤积癖。先比较三种策略：生存优先、设备建设优先、主动战斗/风险优先；策略必须使用公开观察和合法动作，不能读取未来池或随机结果。统计不稳定时再扩样本，不用少数种子直接下结论。

候选算法改变后，同种子不保证相同路线。对比需同时记录候选与选择，并补充固定事件状态测试；不要把旧轨迹重放失败当成新规则错误，也不要把路线差异全部归因于某个奖励值。

| 检查维度 | 必须观察的内容 |
|---|---|
| 节点是否有意义 | 因材料不足只能离开的比例；无效占位必须为0；保底候选是否真的可获得收益 |
| 选择是否有取舍 | 分属性缺口、设备、轮次统计分支选择；若某非条件分支在各种状态下都占优，调整或删除 |
| 生存压力 | 生还率、死亡航次、生命/SAN/缺食水死因；挑战与剧情分开报告 |
| 设备价值 | 首个食水设备/灯的建成轮次、升级率、生产实际使用、无设备策略是否长期同样稳定 |
| 资源经济 | 各类资源获得/消耗/弃置；尤其木头在燃料、制造、维修和战斗中的竞争 |
| 战斗价值 | 入战/撤退率、平均损血和筏损、奖励实际用途；事件不能全面挤掉战斗收益 |
| 风险收益 | E10各段继续率、实际伤害、净资源；E12修复负担和有没有隐含设备损失 |
| 容量负担 | 被迫弃掉有用牌的频率、收尾点击数；不能只靠增加奖励制造清垃圾工作 |
| 存档与自动推进 | 每段保存恢复、失败回滚、奖励不重领；0 AP但有免费选项时不能跳过事件 |

暂不设“生还率必须达到某个百分比”的结论性目标；先确认各路线都能出现合理取舍，资源不足仍有决策空间，然后结合目标难度决定数值。

## 11. 建议优先讨论的三个决定

1. 认可“基础收益通常免费，材料用于定向或加码”的原则后，先采用第一批六个事件与营地拆分，看是否解决空手到站与营地一枝独大的问题。
2. 从新增能力中优先实现E08维修服务和E10分段探索，分别让木筏状态与风险决策进入事件；E11强敌分支可后置。
3. 全部数值保留为试测：尤其营地恢复4/20/20/20、E10概率75%/55%、E12大额格损奖励和商店食水2币，需要同一版经济下验证。

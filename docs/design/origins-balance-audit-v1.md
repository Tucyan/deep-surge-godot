# 出身 v1 数值审视

> 本页评估的是v24旧规则。三种出身已按后续确认方案更新，当前见[出身v2](../origins-v2.md)；本页样本与建议不是新版平衡结论。

2026-10-18。评估范围：当前 Godot v24、单层挑战流程、八种启用出身；不改变正式数值。

## 判断标准与结论

以草案的“出身促成不同建设顺序、资源用途和冒险意愿”为预期，而非要求不同资源收益逐项相等。目前身份方向基本成立，但还不足以认定数值平衡符合预期：行动派的机会覆盖面明显更广，设备匠的专精补偿偏少，战斗狂高档成长兑现偏晚；交易出身的机会和实际成交缺乏有效验证。

以下判断区分代码可推导的数值和有策略偏差的自动样本。测试通过只证明规则行为，不能证明强度相当。

## 逐项分析

| 出身 | 可核对的边际收益 | 初步判断 |
|---|---|---|
| 行动派 | 每航次多1基地AP，每战斗回合多1普通AP；12航次基础额度多12AP，是否兑现取决于实际使用 | 强而稳定的通才基准。额外AP能被完好网放大，可能挤压专精出身的选择理由，尚不能据此认定胜率最高 |
| 设备匠 | 首台滤水器、土盆各提前1进度；每航次首次升级返1AP。Ⅰ级设备保持周期2时，每类累计产品相对普通设备只领先0或1张，并非持续增产 | 优先复测的偏弱候选。普通升级AP节省无法超过行动派每航次的无条件额外基地额度，主要差异依靠提前食水启动兑现 |
| 战斗狂 | 每回合1受限战意；普通连续胜利第3场起额外2材料，第6场起3材料 | 战斗方向成立；7级档可能在Boss后才兑现。不能用终点多发材料代表中期成长有效；战意也可能间接腾出普通AP去打捞 |
| 囤积癖 | 无箱容量13；Ⅰ/Ⅱ/Ⅲ级单箱时17/21/25，对照普通单箱13/16/19 | 稳定但取决于原本会弃掉哪些有价值物资。不是每航次自动多3～6张材料，暂不建议削减 |
| 强壮之人 | 初始生命及上限+4；每航次首张有效包扎3→4，受溢出截断 | 容错定位合理。相对初始HP的增幅随简单/困难/噩梦为33%/40%/50%，需要分别测，不能只用简单结果认定通用平衡 |
| 愚者 | 10～15次移动理论少付50～75 SAN；每个实际侦察航次首次另省4 | 无稳定燃灯时价值高；有灯、恢复溢出时真实收益缩水。不直接推断其持续省材料，也不能把账面SAN全计为有效收益 |
| 无魔之人 | 水母中毒、守卫与Boss畏惧免疫；每战第一次清污染省1AP | 对应敌人上的专精成立，Boss中也有用途；快速击杀和无状态敌人时收益低。暂不扩成全负面免疫 |
| 海上掮客 | 起始3币；当前唯一正式商店节点最多访问2次，首店/次店各购设备才得到1+2折扣，理想合计6币边际预算 | 有启动价值，但上限及兑现受商店时机约束。首店滤水器/土盆4→3，可用出身起始币买入；不能仅按币数判弱，也不能假设每局都兑现6币 |

上述均不把设备本身收益、通用等级AP或局外科技算作出身独有收益。囤积癖表格不含其他容量增益。

## 已有整局证据的可解释部分

`evidence/origins-v1-playthroughs.json` 的seed22记录：

- 战斗狂3次胜利：第8航次额外1张、第11航次1张、第12航次Boss胜利3张。合计5张，但3张到终点才到账，无法用于后续航行投资。
- 设备匠第6、8、9航次分别返1AP，共3AP。不能把“每航次一次”的文字理解为实际拿满12AP。
- 强壮之人2次触发额外治疗，账面多2点，实际有效治疗仍受上限影响。
- 囤积癖弃牌0张，其他出身有2～6张；路线、产出和战斗次数不同，不能把差值直接当作因果收益。
- 海上掮客第11航次抵达商店，却没有任何shop来源设备；这反映自动玩家没有兑现交易能力，无法据此得出该出身弱。

## 自动策略限制

现有 `tools/smart_playtest.py` 使用统一建设优先级，非出身专属策略。它在story阶段先选事件选项再尝试shop_enter，且购设备逻辑以字符串判断stock，而当前stock为报价字典；可能跳过正式交易。战斗部分多处只用普通AP计算余量，治疗阈值仍按3点而非强壮的4点，容量判断也未完整计入箱子。它适合验证普通流程，不能作为优化后的出身策略或公平强度排行榜。

新样本使用 `tools/audit_origins_balance.py`，每局独立Agent进程，简单挑战模式、无局外购买、默认随机起手、seed22/31/42，每局最多500步。每个出身的奖励抽取可能改变后续奖励序列；同种子不保证路线、掉落相同。原始结果逐局保存至 `evidence/origins-balance-sample.json`。结论以实际落盘条目为准，不把未完成条目算成通过。

本轮实际完成24/24局，八种出身各3局，全部为finished/survived，引擎错误0。该简单难度样本的完成率已饱和，无法据此给出可靠强弱排行；未覆盖困难、噩梦、高局外成长或出身专属优化策略。

## 调整优先级（候选，尚未实施）

1. 先处理设备匠的覆盖不足：可试“每航次首次制造或升级滤水器/土盆，完成后返1基地AP”，共用一次额度，替代现有全设备首次升级返还。保留首台预装进度。它提高早期触发率，同时避免把战斗设备、网和生产设备都一起免费化；需与原方案对比。
2. 若希望当前单层内明显体验战斗掉落成长，可对比1/3/5级分别额外1/2/3张，替代1/4/7；不增加经验。该方案会加强中期经济，不能与“已经平衡”等同，需要同时记录额外材料的使用和弃置。
3. 暂时保留行动派，先验证网与战斗打捞是否使其收益失控，不同时提高全部专精数值追赶它。若发现低风险拖延获利，应单独评估通用战斗规则。
4. 海上掮客先用可正确进入商店、购设备的策略验证，并记录首次交易航次、折扣次数、实际买入设备及其回本；不先加起始币或每店固定设备。
5. 强壮、囤积癖、愚者、无魔先维持数值。后续要覆盖困难/噩梦、低/高局外成长和至少一套偏向该出身的策略，再决定调整。

没有修改正式规则、内容版本或玩家存档。以上是初步数值审视与候选调整，不是已经确认的平衡补丁。

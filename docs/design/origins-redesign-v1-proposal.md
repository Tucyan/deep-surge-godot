# 出身设计草案 v1

日期：2026-10-18。状态：**讨论提案，未实施、未进行平衡试玩**。

> 实施更新：八种出身已按v24接入，拾荒者按用户要求禁用，详见[当前出身规则](../origins-v1.md)。本页保留实施前设计原稿，原有“未实施”表述为起草时状态，不代表当前完成范围。

基于当前 Godot `godot-flow-v02-23` 与[局内运营梳理](run-strategies-and-origins-proposal.md)。本版完整列出九种候选，保留现有六种身份并增加三种运营出身；不代表九种需要同时上线。所有数值为首次试测起点。

## 1. 设计目标与共同规则

出身应让玩家在同样的节点和起手下，产生不同的建设顺序、资源用途和冒险意愿。

- 每种出身提供一个主要经营优势，最多配一项支持该方向的能力。
- 战斗狂通过玩家等级放大战利品；生产、打捞和仓储通过设备发展强化能力；通才和抗性出身可以保持固定效果，不强制共用一套出身经验条。
- 本版不新增全员通用的出身升级币、天赋树或独立熟练度；不要求非战斗路线为了激活出身而刷经验。
- 新方案为各身份的完整效果清单。未列入的旧效果不默认继续叠加；当前程序仍保持原规则。
- 基地AP、普通战斗AP、战斗狂专用AP分别说明。每航次效果只在真实新航次刷新，战斗回合、开关面板、离店重进、存读档不刷新。
- 设备失效时，依赖该设备的增益同时失效；修补后恢复。奖励超限照常接收，轮末按正式规则整理。
- 不给出身额外改变剧情、好感或剧情存档的权限；教程保留固定教学配置。

## 2. 九种出身总览

| 出身 | 希望玩家更愿意做什么 | 核心优势 | 仍要解决的问题 |
|---|---|---|---|
| 战斗狂 | 主动迎战，用战利品继续发展 | 战斗专用AP；随玩家等级成长的胜利材料 | 恢复、筏格战损、容量、合适的战斗机会 |
| 拾荒者（新增） | 建网并用打捞补齐关键配方 | 首次基地打捞定向获得材料，高级网提高精准度 | 普通制造AP、材料总量、容量 |
| 设备匠（新增） | 早投资食水设施，再合并升级 | 首台食水设备加快启动，升级节省AP | 建造材料、维修、燃料、回本时间 |
| 囤积癖 | 保留关键物资，利用储备应对坏情况 | 较高基础容量，箱子提供额外容量 | 产量与战斗能力不会自动增加 |
| 强壮之人 | 承担风险，靠恢复维持连续行动 | 更高生命及治疗效率 | SAN、食水及持续高伤害 |
| 愚者 | 少受精神压力限制，更敢选择航线 | 航耗减轻、首次侦察便宜 | 生命、战力、材料都仍需经营 |
| 无魔之人 | 挑选状态型敌人，减少消耗 | 明确的状态免疫与有限污染处理 | 直接伤害、筏格损伤不受保护 |
| 多动症（可展示为“行动派”） | 灵活切换打捞、建设和战斗 | 基地/战斗AP各+1，作为通才基准 | 没有额外战利品或定向物资 |
| 海上掮客（新增） | 留钱找商店，按货架调整建设 | 起始贝币、随商店访问增加的设备折扣 | 货架随机、限购、商店可得性 |

## 3. 战斗狂——靠胜利滚动发展

重做现有“战斗狂热”，建议展示名为“战斗狂”。

**能力：战意。** 每个玩家战斗回合获得1点专用AP，可支付固定攻击、固定格挡、矛击或清除污染。优先消耗此点，回合结束清零；不能用于打捞或任何基地操作，0AP动作不消耗它。

**能力：胜者掠获。** 每次实际战斗胜利，按结算完本场经验后的玩家等级，在原奖励上额外发永久基础材料：

| 战后玩家等级 | 出身额外材料 | 当前普通战斗材料合计 |
|---|---:|---:|
| 1～3级 | 1张 | 2张 |
| 4～6级 | 2张 | 3张 |
| 7级及以上 | 3张 | 4张 |

额外牌从五种基础资源等权有放回抽取。普通、遗迹、分支战斗和Boss胜利均可触发；撤退、离开、保护败退与死亡不触发。每场只结算一次。

不额外增加经验、回血、尸体、贝币或容量；建议替换原撤退免生命代价。通用等级成长照常，不因出身再重复结算。连续普通胜利第3场到4级，第6场到7级，均可让当场奖励提高。

**运营变化：** 更重视弓弩、盾架、恢复和可赢的战斗。早期用额外材料改善战力，中期提高每场胜利的经济回报。

**玩家说明：**“每回合多1点战斗专用AP。胜利额外获得1张基础材料，战后4级升为2张、7级升为3张。”

## 4. 拾荒者——让打捞补到真正缺少的材料

**能力：定向打捞。** 每航次第一次基地打捞前，指定一种基础材料；该次原有保底1张直接变为指定材料，其余网产出照常随机。打捞费用仍为1基地AP，不增加保底张数。

**设备联动：熟练筛选。** 若本次打捞时存在完好、已安装的Ⅱ或Ⅲ级捕捞网，该次结果中的第一张额外网产出也变为所指定材料。一次最多定向2张，不按网数量重复触发，Ⅲ级不再多加定向次数。

定向类型在执行前确认；未确认不消费、不抽取。只对本航次第一次基地打捞有效，战斗打捞既不享受也不消耗该资格。基础产量、其他随机张数及增压规则不变，定向替代的随机抽取如何处理须在实现时明确版本化。

**运营变化：** 更容易补齐绳索、塑料等短缺材料，减少为一张材料反复打捞或付费3换2。高级网使建设计划更可靠。

**玩家说明：**“每航次首次基地打捞的保底材料可自选；拥有完好Ⅱ级以上捕捞网时，再定向1张网产物。”

## 5. 设备匠——尽早投入，尽早开始回本

**能力：预装调试。** 本局首次亲手制造的滤水器、首次亲手制造的土盆，各携带1点初始生产进度。安装不直接发牌，只在后续真实轮初推进和生产。该资格每类仅一次；购入或局外发放的设备不触发，原子制造升级不额外生成进度奖励。

以当前Ⅰ级周期2为例：通常第N轮安装后在N+2轮初首次生产；本能力使首次产出可提前到N+1轮初。若升级后周期改变，按新周期在真实轮初结算，不立即补产。

**能力：熟练改装。** 每航次第一次成功升级设备后返还1基地AP，最多返还本次实际支付的AP；不返材料。制造、安装、维修不触发。原子“制作并升级”原费用2AP，完成后返1AP，仍需先满足原费用才能执行。

升级不改变原有合并成本、同级要求、燃料和进度保留规则。失败、预览、取消、再查看不触发返还。

**运营变化：** 更愿意早做食水设备、保留同类设备进行升级，以产能减少后续补给压力。制造投资依然需要真实材料。

**玩家说明：**“本局首次制造的滤水器、土盆各预装1点生产进度；每航次首次成功升级设备返还1基地AP。”

## 6. 囤积癖——保留物资，保留选择

**能力：随身储备。** 基础手牌容量+3，替代原来的+1。

**设备联动：分类收纳。** 按当前最高等级的一台完好、已安装储物箱，额外提供1/2/3容量。不逐箱叠加；没有有效箱子时为0。箱子本身原有容量仍照常。

例如只有一台Ⅰ级箱：无其他增益时容量为10+3+3+1=17；升级到Ⅱ级后为10+3+6+2=21。箱子破损时，其原容量和出身联动同时失效；轮内允许超限，仍到轮末整理。

不改变普通材料每张占位规则，不按持牌数量生产资源，不让贝币额外占多格。

**运营变化：** 可以留修补、治疗与未来配方材料，在补给充足时提前储备。收益取决于能否把保留的物资用在关键时刻。

**玩家说明：**“手牌容量+3；最高等级的完好储物箱额外提供1/2/3容量。”

## 7. 强壮之人——用生命余量承担冒险

**能力：强健体魄。** 初始生命与生命上限+4；本版不再附带旧食水上限加成。

**能力：恢复力。** 每航次第一张能实际恢复生命的包扎包，治疗量+1，即当前3变4。满生命使用不消耗本资格；溢出治疗直接截断，不转成护盾或材料。战斗中和基地共用本航次一次资格，营地恢复不触发。

通用升级增加生命上限时依旧不回血，不因低血、挨饿、撤退或故意受伤发放额外奖励。

**运营变化：** 有更高生命缓冲，布条和包扎投入更划算，适合承担事件或战斗风险。仍需控制连续战损。

**玩家说明：**“生命与上限+4；每航次第一张有效包扎包额外恢复1生命。”

## 8. 愚者——精神压力下的航线自由

**能力：随波而行。** 每次实际移动的基础SAN航耗减少5，即通常15降为10；先计算航耗修正，再按原规则结算灯和崩溃。灯的恢复与燃料不变。

**能力：无畏窥探。** 每航次第一次有效侦察只需SAN4，之后仍为8；支付后至少剩1。已公开、无效、取消或失败的侦察不消费资格，不重抽节点或奖励。

本版以这两条替代旧的通用精神损失减免，不减免事件主动支付、不免疫精神崩溃，不改变环境概率或偏航判定。旧夜间成本减免不作为新能力保留。

**运营变化：** 可以减少早期燃料压力，用更低代价判断隐藏节点，在休整和冒险间拥有更大选择余量。

**玩家说明：**“移动精神航耗少5；每航次首次侦察仅消耗4精神。”

## 9. 无魔之人——抵抗状态消耗

**能力：异质抗性。** 免疫敌人施加的中毒与畏惧。范围采用明确名单，未来新状态不会自动免疫。

**能力：清醒。** 每场战斗第一次主动消除一张污染牌不消耗AP，后续清除照常；必须真实移除污染牌才消费资格。一次只清一张，不阻止生成，不抵消留手扣血。

不免疫直接生命伤害、筏格破损、拖延伤害、环境、事件支付或精神崩溃；不改变箭、盾和其他战斗设备收益。

**运营变化：** 更愿意面对状态型敌人，减少为解状态消耗材料与行动的压力；与战斗狂的奖励成长形成不同战斗倾向。

**玩家说明：**“免疫敌方中毒、畏惧；每场首次主动清除污染不耗AP。”

## 10. 多动症／行动派——灵活通才基准

**能力：精力充沛。** 基地AP上限+1、普通战斗AP上限+1，保持现有效果。可考虑将展示名改为“行动派”，内部身份是否更名留到实施时决定。

不额外增加产量、掉落或专属成长。普通战斗AP仍可按原规则用于打捞，这也是它与战斗狂专用AP的差异。

**运营变化：** 更多AP可灵活用于造设备、打捞、修补或战斗，适合随节点转向。作为比较其他出身强度的通才基准，首轮不额外加能力。

**玩家说明：**“基地AP与战斗AP上限各+1。”

## 11. 海上掮客——让有限商店机会更值钱

**能力：周转金。** 开局获得3贝币，与局外开局币相加，不额外占多份贝币容量。

**能力：熟客价。** 本局第一家商店首次成功购买设备，价格减1；第二家及以后每家首次成功购买设备，价格减2，最低1币。先按既有优惠券规则计算，再扣此出身折扣，最终至少1币。

折扣仅用于设备，不用于基础材料；进入不同商店计访问序号，重复打开同一商店不增长。每店只对一件实际成交设备生效，预览、取消、余额不足不消耗；未用折扣不累计。活动商店数量和候选规则不变。

不放开基础材料出售、不刷新货架、不重置共享涨价。当前设备每张出售1币，最低购价也为1币，不能靠本折扣买卖同物获利。

**运营变化：** 更愿意保留贝币，在商店直接补齐设备或准备同类升级件；后续商店价值更高，但仍要应对不合适的货架。

**玩家说明：**“开局获得3贝币；每家首次购设备享折扣，首店减1币，后续店减2币，最低1币。”

## 12. 首轮测试重点与建议批次

第一批建议六种：**战斗狂、拾荒者、设备匠、囤积癖、强壮之人、行动派**。覆盖胜利成长、定向资源、生产投资、库存、生命和AP六种收益。愚者、无魔之人、海上掮客作为第二批候选，补导航、状态与交易分支；原版身份在正式替换前仍按旧规则存在。

| 出身 | 最需要验证的风险 | 首选调整手段 |
|---|---|---|
| 战斗狂 | 间接腾出普通AP刷打捞；材料成长过快；7级太晚 | 调整掉落阈值/张数，观察战斗回合数，不立即叠经验倍率 |
| 拾荒者 | 定向使3换2失去用途，或Ⅱ级网门槛太慢 | 调整定向次数/设备门槛，不继续增加随机总产量 |
| 设备匠 | 开局进度和AP返还让升级过快 | 收窄返还适用设备，或降低调试覆盖数量 |
| 囤积癖 | 高容量无须取舍，或只有纸面容量无实际收益 | 调整基础加成与箱子联动，观察保留物资的真实用途 |
| 强壮之人 | 与永久体质叠加后，长期缺食水的生命代价过低 | 对照不同局外成长；调整起始生命或恢复次数 |
| 愚者 | 侦察机会过少，或长期灯的经营意义过低 | 调整侦察折扣与航耗减免，两项分别测 |
| 无魔之人 | 对特定敌人几乎无代价、对其他敌人又无收益 | 调整免疫为有限抵抗前先测，不扩成全负面免疫 |
| 行动派 | 通用AP+捕捞网仍优于全部专精 | 先作为基线测量，不直接给其他出身更多全局AP |
| 海上掮客 | 没遇商店时被动失效，或起始币/折扣组合偏强 | 记录商店可达性和实际成交，不强制刷专属商店 |

比较条件应固定难度、起手、种子组和局外成长档位，分别观察低成长与高成长，不用单一种子推断强弱。记录通关、生存成本、有效资源投入、弃牌、设备组合、战斗拖延与出身触发率；额外随机抽取会改变后续奖励流，同种子不保证逐张奖励相同。

本次仅完成设计与静态数值核对；没有新增运行代码、身份数据、UI、版本迁移或存档字段。新增触发资格、进度携带、折扣和专用AP均需后续实现、保存恢复及正式回归验证。

# 局内运营路线、玩法扩展与出身增益草案

日期：2026-10-18。状态：**讨论草案，未实施、未进行平衡试玩**。

> 实施更新：八种出身已按v24接入，拾荒者按用户要求禁用，详见[当前出身规则](../origins-v1.md)。本页保留实施前设计原稿，原有“未实施”表述为起草时状态，不代表当前完成范围。

依据当前 Godot `godot-flow-v02-23` 的代码和正式内容，服务于“整理当前运营思路，并让出身强化不同运营路线”的讨论。第1～3节梳理现状及其策略含义；第4～8节均为后续提案，不覆盖现行契约。当前机制文档页首版本尚为v22，本文核对了v23代码相关分支。

## 1. 玩家每局实际在经营什么

核心决策是：**把有限的材料、AP、筏格和生存余量，投入哪种能在剩余航程内回本的收益循环。**

| 要经营的资源 | 当前用途 | 主要取舍 |
|---|---|---|
| 基地AP | 打捞、制造、转换、升级、修补、扩建 | 现在拿材料，还是投资后续产能；同一轮导航、准备、收尾共用 |
| 战斗AP | 攻击、格挡、矛击、清污染、战斗打捞 | 快速获胜、降低损伤，还是承受风险多拿资源 |
| 材料手牌 | 制造、燃料、维修、战斗组合、3换2 | 消耗一张可能同时放弃另一条路线的投资 |
| 筏格 | 放置生产、战斗、容量和增益设备 | 初始只有4个功能格，新增设备未必比升级更合适 |
| 生命、食水、精神 | 支付生存与冒险成本 | 维持高余量，还是用部分余量换发展；生命损失不等价于材料损失 |
| 手牌容量 | 保留生产成果、材料、恢复牌和战利品 | 毛产量只有被消耗或留存后才有价值，轮末弃掉的牌不等于有效收益 |
| 剩余航程 | 给设备、成长和库存兑现价值的时间 | 临近终点时，长周期投资可能来不及回本 |

手牌是库存，当前没有循环抽牌牌库。“战后额外掉落手牌”应解释为新增永久物资牌；要进一步指定牌池，不能含糊地把临时战术牌、设备和基础材料都算成同一收益。

当前常见转换链：

```text
AP → 打捞材料 → 制造/升级设备 → 更多材料、食水、战斗供给或容量
战斗投入 → 胜利 → 经验、材料、贝币、尸体
尸体 → 灯燃料 / 发电机燃料 / 商店贝币 / 3换2的投入
食水与精神供给 → 减少被迫补给 → 更自由地选战斗或发展节点
容量与修补 → 保住已有收益 → 让前面投入真正兑现
```

## 2. 当前已经成立的运营路线

以下是依据代码推导的玩家思路，不表示它们已通过同条件胜率比较，也不表示开局就必须锁定一种路线。

| 路线 | 玩家实际怎么做 | 收益循环 | 主要瓶颈 |
|---|---|---|---|
| 捕捞发展 | 早造网，把可支配AP投入打捞，再补箱子、转化和生产设备 | 更多材料支持更多建设；多网和高等级网放大每次打捞 | AP、容量、缺指定材料、网所在筏格破损 |
| 食水生产 | 用土盆、滤水器建立续航，适时升Ⅱ级，配灯保障精神 | 减少对补给节点的依赖，把路线选择让给发展与战斗 | 前期材料和制造/升级AP、生产等待、格子占用 |
| 以战养战 | 弓弩、盾架及已解锁的矛架支持连续战斗，战利品再投战力和恢复 | 战斗→经验/尸体/贝币/材料→更强战斗准备 | 真实掉血、中毒污染、筏格损伤、恢复不足及战斗候选可得性 |
| 尸体能源 | 战斗供尸体，灯稳定精神，发电机把燃料变战斗或生产增益 | 战斗→能源→增益→后续战斗/生产 | 首具尸体、燃料分配、生产周期；尚未形成完全独立路线 |
| 储备应变 | 造箱子保留绳、布、食水和关键配方材料，遇缺口立即转向 | 保留选项和抗波动能力，减少被迫弃掉高价值储备 | 容量只保住价值，本身不生产；过早囤积会拖慢发展 |
| 战利品交易 | 留尸体，在有限商店访问中卖币，买缺失设备或便宜材料 | 战斗→尸体/币→指定设备，减少随机材料卡手 | 商店次数和货架限制；基础材料不能卖，尚无完整倒卖体系 |

目前更完整的是捕捞、食水生产、战斗三条主线；能源、储备、交易更多承担辅助分支。把它们都称为成熟、等强的“流派”会高估当前内容。

几个影响实际选择的数值：

- 无网打捞是1AP得1张随机材料；一台Ⅰ/Ⅱ/Ⅲ级网使每次总产量成为2/3/4张。多台完好网继续叠加，**战斗打捞也享受这些收益**。
- 食水轮末各耗30，单张恢复40；Ⅰ级滤水器/土盆每两次轮初产一张，平均供给20，单台不足以覆盖长期消耗；Ⅱ级每轮一张，理论平均供给40。实际还受安装时机、属性上限和破损影响。
- 普通战胜一次得5经验，当前正好升一级；第5级获得基地与战斗AP上限各+1。因此第4场普通胜利有明确成长节点。
- 各设备升级价值不同：网升级提高主动收益，弓弩升级主要改善箭容量，盾架升级当前没有额外盾量。不能用“能升就升”代替投入比较。
- 食水为0各掉1生命，短期可以承受。玩家可能用生命缓冲腾出发展资源，但这会挤压后续战斗余量；不能未经验证认定每轮食水必须满额自给，或认定长期挨饿最优。

## 3. 一局中的经营节奏

### 前段：先形成一个能运转的循环

先判断眼下是缺生存、缺战力还是缺材料。起手木头/绳索充足时可以考虑网；塑料充足可考虑食水设备；有明确战斗机会时可提前做战斗设备。灯、恢复、修补按真实缺口安排，不要求所有路线都按同一建造表起手。

自选起手上限受难度影响，简单5张、困难4张、噩梦3张；零选则随机发放各档上限+2张。确定材料与多拿随机牌本身就是运营选择。

### 中段：解决主线的瓶颈，再建立第二条供给

- 网产出已经大量溢出：优先考虑容量、转化或立即建设，不一定继续叠网。
- 资源够但制造AP不足：减少低效打捞，把AP用在能及时回本的建设上。
- 战斗能赢但掉血过高：补盾、治疗与缩短回合，不能只看奖励张数。
- 食水稳定但精神不稳：解决灯与燃料，否则稳定生产也无法抵消精神崩溃。
- 设备所在格破损：修补常同时恢复设备收益并避免未来损失，应与造新设备比较。

### 后段：把产能换成终点保障

优先保留恢复、控制材料、战斗设备和必要修补。终点后不再推进下一轮生产，依赖Boss经验才解锁的经济能力也难以在本局继续兑现。挑战模式最终需要击败Boss并活过轮末，发展快并不自动等于完成目标。

## 4. 后续怎样扩展玩法

优先补“同一批资源可以走不同经营循环”的选择，再增加系统数量。

| 顺序 | 扩展内容（均未实施） | 希望增加的决策 |
|---|---|---|
| 1 | 重做战斗狂，并做一两个生产/捕捞方向的对照出身 | 相同节点和起手，在不同出身下出现不同的合理选择 |
| 2 | 补齐弱升级：如盾架、矛架Ⅲ级等；增加有限的设备专精二选一 | 同种设备可以偏即时效率、长期产出或保留能力；每台不必全部选择叠满 |
| 3 | 节点提供公开的收益/成本倾向，补少量支持不同运营的事件 | 选择战斗、补料、恢复或设备机会；避免所有节点都退化成相同的随机材料奖励 |
| 4 | 小规模加入有条件的专精奖励或藏品，再扩能源/交易路线 | 战斗专精强化战利品使用，生产专精改善周期，交易专精改善变现与购入 |
| 5 | 难度和敌人意图检验不同经营短板 | 防止只靠一种高产资源体系应付全部局面，同时保留多种应对方式 |

具体可试的方向：

- **捕捞方向**：在有限次数内改善资源组成，例如每航次第一次基地打捞有一次将结果中一张换成指定基础材料的机会。侧重精准，不继续无限加总张数。
- **生产方向**：让升级选择“更快首次回本”或“更高长期产能”；损坏暂停和修补仍有意义，不让免费生产绕过航行轮。
- **战斗方向**：用公开的普通/强敌分支提供风险选择。先测当前敌人与奖励差异，再扩敌人；避免把所有难度简单变成更多血量。
- **能源方向**：尸体继续在出售、灯、发电机间竞争。后续增益可以提供不同消费场景，但同一具尸体只消费一次。
- **交易方向**：有限订单、设备回收或货架选择可以发展成路线。它们需要新规则；当前不可把材料倒卖或任意刷新商店当作已有能力。
- **仓储方向**：强化保留关键物资、适应坏海况的能力，让“手上留得住”有用途；不按持牌数每轮复制资源。

候选节点不能只为出身服务：先保证基本可玩机会，再考虑很轻的类型倾向。战斗狂仍需要补给，生产出身仍可战斗；不强制每轮刷出专属节点。

剧情目前与资源/战斗隔离。本提案不把好感度或剧情选择直接接入出身经济增益，也不借扩玩法重启旧夜间系统。

## 5. 出身应该怎样强化运营

建议每个出身围绕三个问题设计：**更愿意做什么、为什么做得更划算、发展起来后怎样兑现。** 首轮只给一个核心收益机制和必要的启动支持，避免每个出身同时加AP、产量、容量、回血和减费。

| 出身 | 当前效果 | 建议强化的运营方向（提案） |
|---|---|---|
| 战斗狂热，可展示为“战斗狂” | 普通撤退免生命代价 | 改成战斗专用行动增益＋按局内等级增加胜利战利品，详见下一节；建议替换旧被动 |
| 多动症 | 基地/战斗AP上限各+1 | 当前已是行动效率通才，适合频繁制造、修补、打捞；先作为对照保留，不继续叠产量 |
| 囤积癖 | 手牌容量+1 | 储备与抗波动；可试提高起始容量，或使箱子多提供少量容量，首轮二选一，不同时附带复制牌收益 |
| 强壮之人 | HP及上限+4、食水上限各+10 | 生命缓冲和高风险节点；若需强化，可试每航次第一张包扎包额外恢复1，必须实际治疗且不能溢出转资源 |
| 愚者 | 部分非自愿精神损失减免 | 精神压力下的航线自由，减少燃料和休整依赖；先把适用范围说明清楚，再决定是否扩大效果，不默认减免主动支付成本 |
| 无魔之人 | 免疫敌方中毒/畏惧等状态，不含Boss污染牌 | 抗消耗战斗，与战斗狂的胜利收益区别；先保留免疫边界，若扩展污染处理则另测，不默认获得所有负面免疫 |
| 新出身：拾荒者 | 尚不存在 | 每航次第一次**基地**打捞允许替换一张结果为指定材料，只改善一次组成，不按网数量复制触发 |
| 新出身：设备匠 | 尚不存在 | 首次制造滤水器或土盆时获得1点初始生产进度，每局只触发一次；不当场发产品，之后仅真实轮初推进 |
| 新出身：海上掮客 | 尚不存在 | 每个新商店首次购设备减1币，最低1；不重置资源阶梯，不靠买卖同物循环获利 |

表中数值都是候选试测值，除战斗狂外不建议一次实施整张表。出身不必用负面惩罚强迫玩家只走一条路线，机会成本和增益范围已能产生倾向。

成长来源建议区分：局内等级奖励冒险，设备等级奖励投资，出身奖励某类决策。不要为了让非战斗出身也成长，直接给所有生产和打捞都发战斗经验；那会把目前的战斗成长特色冲淡。

## 6. “战斗狂”可直接试测的完整方案

### 定位与循环

以现有 `zealot` 为重做对象：**更愿意找能赢的战斗，战胜后用额外材料改善下一场准备，随着局内等级提高，单场胜利的经济价值增加。**

```text
战斗专用AP → 更从容地进攻/防御 → 获胜得到经验和额外材料
→ 等级提高，战后额外材料档位提升 → 制造战斗设备、包扎或续航设施 → 挑战后续战斗
```

### 效果一：每个玩家战斗回合增加1点战斗专用AP

- 开战及每次玩家回合开始时获得1点，当回合不用就消失，不累积。
- 可用于固定攻击、固定格挡、矛击和消除污染；原费用与材料消耗照常。
- 仅支付以上行动的AP，不能用于打捞、制造、修补或航行；零AP射箭不会消耗它。
- 进行上述合法行动时先扣专用AP，普通战斗AP不足的部分再按原规则处理；它不改变基地AP。
- 基础战斗AP、通用等级和局外科技增益仍按原规则计算。专用AP固定+1，不再每几级增加一次。

这里的“专用AP”是**新增规则提案**，当前程序只有普通战斗AP。用户设想的“战斗中AP更多”得到保留，但必须明确这个范围：如果直接给普通战斗AP上限+1，额外AP还能每回合打捞永久材料，渔网会进一步放大，容易使战斗狂同时成为高效捕捞出身。

若后续决定采用普通战斗AP上限+1，也应作为单独版本对比测试，不能宣称它和本方案强度等价。

### 效果二：战斗胜利额外掉落永久基础资源牌

| 本次胜利结算后的局内等级 | 出身额外掉落 | 普通战斗原有随机资源 | 普通战斗资源合计 |
|---|---:|---:|---:|
| 1～3 | 1张 | 1张 | 2张 |
| 4～6 | 2张 | 1张 | 3张 |
| 7及以上 | 3张 | 1张 | 4张 |

公式：`额外资源数 = min(3, 1 + floor((结算后等级 - 1) / 3))`。

- 牌池只含木头、废铁、塑料、绳索、布条，等权有放回；不附赠设备、食水、尸体、贝币或临时战术牌。
- 正式普通战斗、遗迹、分支强敌、Boss的**实际胜利**均可触发；在各自原奖励上加本出身奖励，不把基础奖励覆写成普通战奖励。
- 同场只发一次。离开遭遇、撤退、遗迹保护败退、死亡都不触发；教程不使用这一出身。
- 超限照常收下，轮末统一整理；不自动扩容量，不在战后强制立刻弃牌。
- 不额外加经验倍率，不额外回血，不增加尸体或币。等级价值已通过战利品成长增强，先避免再叠经验加速。

### 升级与结算口径

建议新方案先结算本场经验和通用升级，再根据**战后等级**确定额外牌数；原基础掉落先抽，额外掉落随后抽，使用奖励随机流。当前代码先发基础掉落、再结算经验，后续实现必须处理清楚这个差异，不能靠UI自行推算或重复领奖。

初始1级，连续普通胜利后的示例：

| 普通胜利累计次数 | 战后等级 | 本场出身额外牌 | 本场普通资源合计 |
|---|---:|---:|---:|
| 第1场 | 2 | 1 | 2 |
| 第2场 | 3 | 1 | 2 |
| 第3场 | 4 | 2 | 3 |
| 第4场 | 5 | 2 | 3 |
| 第6场 | 7 | 3 | 4 |

通用升级仍保留：4/7/10…级生命上限+1且不回血；5/20…级基地/战斗AP上限各+1；10/25…级容量+1。第5级只结算一次通用AP成长，不因为出身再叠同名奖励。Boss可一次跨多个等级，按最终等级定本场额外掉落，仍封顶3张；这主要是结算奖励，不能把终点升级当成中段成长保障。

建议重做后移除原“普通撤退免生命损失”，使奖励集中在赢下战斗。此为草案取舍，尚未改动原出身；遗迹保护仍按原规则执行。

### 玩家看到的简短说明

> 每个战斗回合额外获得1点战斗专用AP，可用于攻击、格挡、矛击和清除污染。战斗胜利额外获得1张基础材料牌；战后等级达到4级、7级时，额外数量分别提升至2张、3张。

奖励页建议分开显示“原战利品”和“出身额外战利品”，并在升级跨档时说明“战利品加成已提升”。等级指本局玩家等级，不是设备等级或局外科技层级。

## 7. 为什么需要限制叠加，以及先测什么

当前Ⅰ级弓弩每回合产1支0AP、2伤害的箭；盾架每回合产1盾；每台Ⅰ级网额外使一次打捞多1张。在能控制伤害的战斗里，AP与产箭供盾会随回合刷新。第7回合起拖延扣血提供成本，但不能据此认定拖延收益已经被压住。

因此出身奖励绑定**胜利次数和等级档位**，不绑定战斗回合数、出牌次数、造成伤害或使用资源数。战斗专用AP减少直接刷材料的通道，但仍可能间接腾出普通AP用于打捞，必须实测，不能把限制描述为彻底消除问题。

后续若仍出现低风险拖延刷牌，应单独审视通用战斗打捞、威胁升级和胜利速度奖励；这些会改变全体玩家规则，不能在出身实现时顺带修改。

首轮对比：同难度、同起手、同种子、同局外成长，比较现战斗狂热、新战斗狂、多动症，以及一个生产或捕捞出身。多种种子分组，记录实际路线；出身额外掉落会消耗奖励随机流，相同种子不保证后续资源逐张相同。

| 要观察的指标 | 用来判断什么 |
|---|---|
| 中途死亡率、Boss通关率、轮末生存情况 | 强化是否转成真实完成能力 |
| 主动选择战斗次数、战前HP、战斗掉血与维修成本 | 是否产生合理冒险，还是无脑见怪就打 |
| 第4/5/7级到达航次，终点前达到比例 | 成长档位是否在可用时间内出现 |
| 平均战斗回合、战内打捞次数及收益 | 是否奖励故意拖延 |
| 额外材料获得、投入、留存、轮末弃置数量 | 掉落是否形成有效经营收益 |
| 设备组合、升级与燃料分配 | 是否支持多种战斗运营，而非固定唯一建造序列 |
| 原/新出身与局外AP科技的组合结果 | 后期成长是否放大到失去选择空间 |

先用数据决定阈值和上限；若掉落溢出，优先减少额外张数或增加有限选择质量，不同时送容量。若7级主要在Boss后到达，优先调整成长阈值，不能直接假定应多送经验。

## 8. 最小落地顺序与本次边界

1. 只做战斗狂的专用AP、分档战利品和准确说明，保留其他规则，验证其确实改变选战与经营。
2. 做一个对照出身，优先拾荒者或设备匠；观察相同开局是否出现不同合理决策。
3. 补少量节点分支和低价值设备升级，再决定是否增加藏品或完整贸易玩法。

# 自动结束行动与包扎包、矛架修订

2026-10-15 架构整理：AutoProgress改为消费 `core/action_query.gd` 的统一有效操作查询，木筏报价和Agent操作共用同一命令校验。探测在捕获的活动状态副本上执行，禁用副本自动后续命令，不再经存档恢复/迁移；活动局自动结束规则保留。见[Agent接口](agent-interface.md)。

2026-10-14 用户需求，Godot V0.2。

- 节点结果确认后进入收尾；没有任何有效基地行动时自动执行 `end_voyage`。合法合成、可恢复属性的生存牌、安装/修理/升级/扩建/行动牌及免费添燃料都会保留行动机会。不能因原料牌标记0 AP就视为可直接出牌，不能因恢复牌存在就忽略属性已满。
- 自动结算先处理老化和临时增益到期，再进入超限弃牌。容量达标后先扣食水与饥渴生命损失，存活才进入下一轮生产与导航，超限需手动选牌；导航、准备和事件选择不会自动跳过。剧情第5～14站按原顺序进入夜间服务，不能绕过夜间安排。
- 战斗AP为0且没有有效0 AP卡牌时自动执行敌人回合、回合数推进、AP设值及设备供给。射箭/有效恢复牌会保留当前回合；胜利返回结果剧情，死亡进入结算，不能继续敌人回合。敌人回合只自动执行一次。
- 合法性用隔离状态副本调用真实规则判断，不写入活动状态、统计或规则随机；自动命令独立记录revision与统计，成功操作后统一保存和重绘。非法命令、查看/关闭面板不触发自动结算；继续游戏会检查是否需要推进。
- 包扎包：合成配方/AP成本不变，产物改为生存牌，0 AP使用，恢复生命8，消耗一张，不安装、不额外消费布条；基地和战斗均可使用。恢复量沿用旧基础量，是此次实现选择。
- 矛架：仅每场战斗开始发一张临时矛，后续回合不补发；基础伤害3，二级起伤害5（本次未增加另一个三级伤害值），矛使用仍需1 AP。弓弩的每回合产箭保持原规则。
- 兼容此次修改之前的 `godot-flow-v02-4` 内容指纹；活动存档中的旧包扎设备转换为一张一次性包扎包并腾空筏格。旧终局报告保持冻结。equipment表的medkit项仅保留旧存档识别与表现兼容，新牌不能安装。

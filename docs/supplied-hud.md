# 用户提供的 HUD 包接入（2026-10-13）

来源为 `deep_surge_complete_hud_godot4.zip`，原包、完整解压文件及 SHA 清单保存在 `asset-sources/complete-hud-v1/`，该目录以 `.gdignore` 排除运行导入。包实际包含三个程序绘制的 Control，没有图片图集、3D 模型或新玩法内容。脚本经检查，运行组件只使用 Godot 绘制、原生控件与信号，不含文件访问、网络访问或外部命令执行。包内 README 为参考资料，不替代项目规则。

## 实际接入

- `ui.hud.status`：右上生命、饱食、水分、理智图标与状态条。映射真实 `hp/hunger/hydration/sanity` 及各自上限，不采用 demo 默认值。
- `ui.hud.action-points`：右侧行动点圆标，航行使用基地 AP，战斗使用战斗 AP；夜间显示今晚机会；结束状态不展示。
- `ui.hud.event-choices`：已有剧情/遭遇子页面的选择区域，继续、跳过、迎战、离开、商店入口和选项全部映射原有命令/稳定选项 ID。事件仍按阶段触发，收起面板不结束事件。
- 两个表现适配资产 `ui.hud.voyage-adapter`、`ui.hud.story-adapter` 记录页面依赖和 hash。登记工具为 `tools/register_supplied_hud.py`。

运行组件放在 `addons/deep_surge_status/`；直接实例化，不需要启用编辑器插件。包内 demo、plugin.gd/plugin.cfg 和 project.godot 只保留在原始来源目录，不覆盖当前项目设置。

## 适配

沿用游戏中文字体，增大状态条字体，调整 AP 圆标间距以免与标签重叠。事件面板保留费用、选项说明与不可用原因，可禁用且阻止禁用选项发送命令。未添加滚动容器，保留现有全部手牌重叠/悬停展开交互。

## 手牌摊开修正与动画（2026-10-13）

`ui.hand.fan` 升至 v2。此前第二张牌悬停时，左侧只有一张牌，但排布将其固定在底板边缘，留下过大的左间距。现在从悬停牌向两侧以相同相邻间距排布，远端按剩余空间压缩；牌多时仍允许重叠，不分页。第一帧直接定位，后续抬起、摊开、切换与回位使用 0.18 秒响应的指数缓出插值，快速换牌从当前显示位置追随新目标，不堆积 Tween。动画命中检查继续使用实际绘制位置，规则/随机/卡牌 UID 不参与动画。

回归验证 `HAND FAN: PASS`：包括第二张牌左邻间距、移动有中间帧且不瞬移、回位动画、两种分辨率边界、24 张连续手牌、真实鼠标点击与规则快照不变。`CLEAN HUD` 和 68 项资产 hash 检查通过。GPU 检查了航行与战斗手牌；第二张牌前后对照为 `evidence/hand-second-before.png`、`hand-second-after.png`。动画时长为 `move_duration` 导出参数。

## 手牌局部让位 v3（2026-10-13）

悬停时仅左右各两张邻牌让位：最近邻移动不超过牌宽 26% 或基础间距 45%，第二邻为最近邻的 35%；远处牌保持基础位置。空间能完整摆开时按牌宽+8 排布，悬停仅上抬选中牌，其他牌不移动。保留 v2 的平滑过渡、实际位置命中和详情显示。少/多手牌、邻牌位移上限、远牌固定、动画与实际 UID 点击回归 `HAND FAN: PASS`；GPU 已检查，68 项 hash 验证通过。

## 手牌按重叠让位 v4（2026-10-13）

取消固定牌宽百分比和固定第二邻让位。仅计算每张邻牌与悬停牌的实际重叠宽度 `max(0, card_width-step*distance)`，清除重叠时不附加空隙；无重叠的邻牌完全不动。极密集时以基础间距 45% 为位移上限，维持牌序，其余遮挡由悬停牌置顶处理。保留最多左右各两张、少牌不移动和平滑动画。实际 GPU 已检查，手牌回归与 68 项 hash 检查通过。

## 点击连续性与左侧半牌重叠 v5（2026-10-13）

点击使用/查看会导致 FlowApp 重建页面；此前新 HandFan 丢失当前位置和悬停，直接以默认排布出现，形成抽动。现在仅在表现层按稳定卡牌 UID 记录实际位置、悬停和详情，再按 voyage/battle 分别恢复；消耗后存活牌从点击前位置继续动画，已消耗 UID 不恢复，新局清除旧表现状态。该记录不写入 GameState 或存档，不修改规则、随机与点击费用。

左邻让位只清除超过半张牌宽的重叠，悬停牌可以遮住左侧牌一半；右侧保持原先实际重叠让位，最多影响两侧各两张。少牌无需让位、动画及实际坐标命中保留。本次 `HAND CLICK CONTINUITY`、`HAND FAN`、GPU 场景和 68 项 hash 检查通过：真实淡水效果与 UID 消耗、查看/使用后存活牌精确接续点击前位置、悬停身份保留、左侧半牌限制。

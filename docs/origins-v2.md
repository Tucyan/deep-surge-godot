# 出身规则 v2

2026-10-21核对，Godot内容版本 `godot-flow-v03-03`。囤积癖、设备匠保留v25触发，战斗狂权重改为当前层相对乘数；其他出身及教程隔离保留，拾荒者继续禁用。数值为试测，尚未确认整体平衡。

## 囤积癖

保留基础容量+3，移除原来的最高等级储物箱额外容量；箱子本身3/6/9容量不变。

| 手中永久物资数量 | 效果 |
|---|---|
| 0～7 | 搜集欲：每航次首次满足低库存条件的基地打捞，额外获得1张永久随机基础材料 |
| 8～11 | 常态，无额外增益 |
| 12及以上 | 储备充足：每个玩家战斗回合开始获得1点本回合护盾 |

永久物资按手中非临时卡牌实例计数，排除贝币和污染；已安装设备、设备增益和临时战术牌不计数。与占用容量数分开计算。

打捞在扣AP和发原奖励前判断条件；额外材料从五种基础材料等权有放回抽取，走奖励随机流，原打捞和网的收益不变。高库存打捞不占用资格，战斗打捞既不享受也不消耗资格；失败不消费，真实新航次刷新。

护盾在开战及每次玩家回合开始、战术补给发放前判断，不是行动中的持续属性。回合中减牌不撤盾、增牌不补盾；同一回合重复补给/预览/读档不重复发放，过回合照常失效。与盾架护盾分别记录来源。

## 战斗狂

原战意和胜利掉落不变：每回合1战意，仅供攻击/格挡/矛击/清污染；按战后1～3/4～6/7级以上额外材料1/2/3张。普通战前离开/战内撤退均扣4生命。

新增好战本能：普通随机导航的当前层战斗类别权重乘1.5（Ⅰ12→18，Ⅱ35→53，Ⅲ45→68，story20→30，按roundi取整），其他类别权重不变。最终出现概率受可用节点、候选去重、冷却及早期安全候选影响，不等于最终概率直接增加50%。

连续两次普通导航的候选均无可主动进入战斗的节点时，下次导航若存在合法战斗节点，替换最后一个候选为战斗，不增加候选总数，保留早期的第一项安全补给。现有普通战斗、遗迹、对决均计入机会；只要候选提供过机会就重置，跳过战斗也重置。

保底遵守轮次、冷却、访问上限，不提前生成非法强敌；没有合法战斗则保底挂起、计数封顶2。教程和固定最终Boss不受影响；不改变独立剧情内容。迷雾仍正常隐藏信息，不强制公开；计数按真实候选计算，但不在只读UI/Agent状态公开该隐藏计数。生成资格和随机状态随保存恢复，查看/侦察/打开界面不重掷；同航次已有候选时不会因再次调用导航生成而刷新。

## 设备匠

移除旧的首次滤水器/土盆预装进度和无条件首次升级返AP，改为两个规模档位。

| 完好已安装设备数量 | 效果 |
|---|---|
| 安装完成后≤4台 | 精工装配：新安装的Ⅰ级设备直接成为Ⅱ级，每类每局一次、合计最多4次 |
| ≥5台 | 规模作业：每航次首次成功制造或升级设备返还1基地AP，两类操作共用额度 |

完好筏格上的设备才计数，破损/脱落和手中设备不计。第4台可精工，第5台正常安装；购入和亲手制造的设备都可精工，已有Ⅱ级不升Ⅲ级。精工支持灯、滤水器、土盆、弓弩、盾架、矛架、发电机、捕捞网、储物箱。拆除、损坏、重新安装、回到低数量、存读档都不重置已消费的类别和总次数。安装不直接发产品，轮初生产按最终设备等级执行。

规模资格在制造/升级消耗之前判断，特别是安装设备作为升级供体被消耗时，不因支付材料本身而失去资格。先满足并支付原AP及材料成本，成功后返1AP；失败不占次数，不返材料。制造包扎等非设备卡不触发。原子“制作并升级”仍先要求完整费用，内部制造不提前返AP，升级完成后共返一次，不附赠旧生产进度。跨越4/5台门槛不会刷新航次额度。

## 其他出身与保存

强壮之人、愚者、行动派、无魔之人、海上掮客沿用[出身v1对应规则](origins-v1.md)，没有追加此前平衡讨论中的候选强化。拾荒者仍在选择页禁用，直接新局/Agent reset/恢复均拒绝。教程继续固定旧教学配置，不激活本次新特性。

`origin_state`包含原来的heal_voyage、scout_voyage、upgrade_voyage、tuned、shops，以及新增salvage_voyage、battle_misses、navigation_voyage。upgrade_voyage现表示规模作业共享额度；tuned现表示已精工设备类别，最多4个唯一合法类别。旧origin_progress字段不再接受。战斗记录origin_shield_turn防止同回合重复护盾。

玩法内容godot-flow-v03-03，旧内容版本玩法档明确拒绝，不自动迁移或覆盖旧文件。独立剧情档版本不变。所有消费均在指令事务中执行，失败回滚资格和随机。只读origin_status提供库存、设备数量和当前公开效果；手牌容量徽章的悬浮提示可查看，Agent也公开同一说明。

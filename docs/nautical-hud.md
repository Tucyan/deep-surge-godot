本页其余为2026-10-17起外观记录，历史夜间夹具不代表当前玩法。本页覆盖此前顶栏、行动点和手牌底板的外观记录，不改变规则、存档内容版本或 Agent 契约。

- 用户按钮参考按长条打捞、圆形合成/迎击两类独立重绘。底色、金边、四芒星和文字分层；原生 Button 保留鼠标、键盘聚焦、悬停、按下和禁用状态。没有把含文字的整张参考图铺成按钮。
- 卡牌区深蓝顶栏、米白底板、双线边框和四角装饰均由 `nautical_frame.gd` 绘制；角饰不随宽度变形。米白填充不透明度为 70%，边框和卡牌不受该透明度影响；底板位于卡牌下方，取消其后被完全遮挡的毛玻璃及屏幕复制。
- **卡牌顶栏固定 56 逻辑像素高**。上下锚点均绑定底边，只横向伸展；纵向只随整个画布/UI 缩放。在相同窗口高度与 UI 缩放下改变宽度，顶栏厚度保持不变，行动点组件不会撑高顶栏。
- 航行顶栏按罗盘、真实航次/阶段、生命/饱食/水分/理智、玩法/设置/首页排列。压缩包的五张 RGBA 图片独立接入，保持原比例；状态轨道与实时数值程序绘制。轨道固定为 72 逻辑像素，不随窗口宽度伸缩；当四等分单元不足以容纳图标、轨道、最大数值文本和边距时，四项同时隐藏轨道，仅显示图标及当前值/上限，航次文字允许省略，环境名称与悬停详情位于航次下方。

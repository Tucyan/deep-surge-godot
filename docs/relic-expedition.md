## 唯一性与奖励品质

6件永久上限类 `crimsonVial/sealedFishTin/tideTablet/copperStill/rescueBadge/redCoral` 使用 `unique:run`，整局只能新获得一次；丢弃保留历史和上限，不能重新刷取。12件持有类使用 `unique:held`，同 ID 同时最多一件；丢弃后可新获得。幽光螺壳、漂流急救包仅有获得时恢复，不限制新实例数量。同一旧UID内部重新持有不执行获得时效果、不增加历史，不属于新获得。

随机奖励抽取前过滤不可获得的唯一藏品，每份重新过滤；空池每份改给贝币2并提示，不中断结算。固定奖励不符合唯一性时明确拒绝且不扣费用。商店引用同一规则，货架不重抽，购买按钮说明限制。

三层Boss胜利各额外掉落一件精选池藏品，保留其余贝币、尸体、材料和经验配置。当前20件稀有度标签均为 normal；品质提升通过精选实际效果实现，没有新增稀有度机制。

| Boss | 精选池 | 选择依据 |
|---|---|---|
| 浅潮 | 赤枝珊瑚、静潮刻碑、归航罗盘、猎潮石矛 | 永久成长、稳定伤害或兼具恢复与容量，支持下一层过渡。 |
| 外海 | 赤潮血酿、叠片残甲、筏匠折尺、备战箭筒、拾荒行囊 | 较高生命成长、护盾、设备升阶、爆发与扩容。 |
| 深渊 | 赤潮血酿、猎潮石矛、缚潮骨刃、筏匠折尺、平安水手结、备战箭筒、三潮矛束 | 战斗与构筑类精选；排除纯恢复和低价值补给。 |

# 手机 UI 阅读与触控布局

当前实现于2026-10-19核对。仍为横屏游戏；UI倍率范围100%～125%，手机默认125%。本次不新增玩法、保存字段或旧版本迁移。

## 设置

手机设置占满逻辑画布，真实移动设备根据系统安全区域留边；顶部“返回 / 设置”和“显示 / 游戏 / 剧情”分类固定，正文单独纵向滚动。标题栏返回及Android系统返回关闭设置并恢复原游戏上下文，底层场景停止接收操作。手机不显示弹窗X和装饰性副标题；桌面仍为700逻辑宽上限的设置弹窗。

手机设置名称22、说明至少18、按钮文字至少20；控件高度至少60，普通按钮宽度下限56。下拉展开菜单文字20并增加行间距；UI滑条保留松开应用，并增加每次5个百分点的减/加按钮。切换分类或应用UI重建时保留各分类滚动位置。航程管理进入“游戏”分类正文底部，避免在所有分类中固定挤占阅读空间。放弃本局仍使用现有确认流程。

## 游戏页面

- 公共手机正文最低18、按钮文字最低20；LineEdit和OptionButton高度最低60。固定美术布局单独处理，不将所有节点整体放大。
- 航行顶部帮助/设置/首页命中区域60×60，关闭按钮60×60；四生存属性保持一行，数值使用22字号，不再强制截断为最多16。
- 手牌名称和费用通过公共文字组件使用手机最低18字号；过长名称省略，原生按钮保留完整操作/无障碍名称。卡牌拖动、战斗选择、手牌容量和叠牌规则不变。
- 手机节点事件隐藏左侧插画，保留可滚动正文与选项两栏，选项栏宽420，操作字20；桌面仍为三栏。
- 手机合成每页最多6个配方、三列，两行内容可滚动；桌面仍每页8个、四列两行。翻页只修改表现状态。
- 手机资源转化按“投入原料→选择目标→确认转化”纵向排列，共用整页滚动。材料卡本身只参与滚动，点击“投入1张”才选料；目标使用“选择”按钮。选料和切换目标后恢复滚动位置，只有执行转化才收费。
- 手机图鉴使用两列预览，详情正文可滚动；遗物仓库每页6格、三列，保留并排详情及其滚动。这里未实施列表/详情分离路由。
- 手机独立剧情文字脱离1600×900整幅构图缩放，改为标题工具栏、滚动正文、滚动选项与继续按钮。正文25、人物名26、说明23，均不再缩字塞框；换段回到正文/选项开头。LOG独立铺满画布、正文22，仍只读并暂停推进。桌面保留原美术构图。
- 教程战斗面板根据提示条的真实高度避让，手机及桌面均不再假定提示条固定不超过88高。

字号和尺寸均为Godot逻辑单位，不等同于Android dp/sp；最终观感与触控舒适度仍需真机校准。未开放150%倍率、未增加独立文字倍率设置。

## 来源与验证

公共尺寸与字体策略位于 `presentation/widgets.gd`、`presentation/text_button_art.gd`；设置位于 `presentation/settings_panel.gd`、`application/page_host.gd`；剧情位于 `pages/story_page.gd`。仅复用现有字体、图片与按钮资源，程序化映射及hash登记于 `assets/manifest.json`。

回归入口：`tests/test_mobile_readability.gd`（支持GPU `--capture`）、`tests/test_mobile_transmute_scroll.gd`、`tests/test_display_settings.gd`、`tests/test_mobile_hand.gd`、`tests/test_mobile_hover.gd`、`tests/test_mobile_scroll.gd`、`tests/test_tutorial_event_layout.gd`、`tests/test_recall_restore.gd`。

当次结果和范围见[验证记录](../evidence/mobile-ui-readability-verification.md)。Android真机、系统安全区域和系统返回事件尚未进行设备验收；发布测试包为 `v0.2.0-20261019-mobile`。

# 手机 UI 阅读与触控布局

当前实现于2026-10-19核对。仍为横屏游戏；UI倍率范围100%～125%，手机默认125%。本次不新增玩法、保存字段或旧版本迁移。

## 设置

手机设置保持整页弹窗，但面板比例固定在 16:9 并在安全区域内居中；两侧多出的区域只由遮罩压暗，不再被面板覆盖。真实移动设备根据系统安全区域留边；顶部“返回 / 设置”和“显示 / 游戏 / 剧情”分类固定，正文单独纵向滚动。标题栏返回及Android系统返回关闭设置并恢复原游戏上下文，底层场景停止接收操作。手机不显示弹窗X和装饰性副标题；桌面仍为700逻辑宽上限的设置弹窗。

手机设置名称22、说明至少18、按钮文字至少20；控件高度至少60，普通按钮宽度下限56。下拉展开菜单文字20并增加行间距；UI滑条保留松开应用，并增加每次5个百分点的减/加按钮。切换分类或应用UI重建时保留各分类滚动位置。航程管理进入“游戏”分类正文底部，避免在所有分类中固定挤占阅读空间。放弃本局仍使用现有确认流程。

## 游戏页面

- 公共手机正文最低18、按钮文字最低20；LineEdit和OptionButton高度最低60。固定美术布局单独处理，不将所有节点整体放大。
- 航行顶部帮助/设置/首页命中区域60×60，关闭按钮60×60；四生存属性保持一行，数值使用22字号，不再强制截断为最多16。
- 手牌名称和费用通过公共文字组件使用手机最低18字号；过长名称省略，原生按钮保留完整操作/无障碍名称。卡牌拖动、战斗选择、手牌容量和叠牌规则不变。
- 手机节点事件改为两栏合并版式（2026-10-20）：左侧整块面板用插画作底图铺满，事件文字压在面板左下的半透明底板上，右侧保留宽420的选项栏。事件页外边距收到左右20、顶边64（教程108）、底边12，面板由1568×578变为1640×644。文字底板不透明度0.70、圆角10，内距18×14，宽度取面板42%（收敛在300～760逻辑像素），高度随文字自适应；文字超出面板高52%时底板先加宽到62%，仍超出则封顶并可手指上下滑动，底边渐隐提示还有更多，手机不画滚动条。操作字20，选项栏内滚动不变；桌面仍为三栏弹性比例（立绘0.94比正文1.06），桌面立绘等比缩放完整显示。
- 手机事件页自2026-10-20起覆盖到手牌区：面板底边贴视口下沿，事件阶段隐藏手牌托盘、手牌顶栏与「合成/转化」入口，选项因此多出约310逻辑像素的高度。桌面仍是原来的布局（事件栏止于手牌顶栏上方）。
- 手机选项栏不显示栏顶的「请做出选择 / 取消选择」行，省下的空间全部给选项按钮；预选后红字「取消选择」出现在该选项右端内侧（避开右侧菱形装饰，触控高56），点它退出预选。桌面仍保留栏顶一行。
- 手机合成不再翻页：所有配方一次列出（三列），内容超出时纵向滚动；底部页码栏取消，说明文字移到材料库存下方；桌面同步改为四列滚动。
- 手机资源转化与桌面同为并排三栏：现有材料／开始转化／选择转化的目标材料；中间确认栏收窄（拉伸比 1.15 对两侧 1.0）。不再有「投入 1 张」按钮和「快捷转化」：点材料卡（图标，右上角 ＋ 提示）加一张，点「开始转化」槽位里的材料减一张；按下后移动超过14逻辑像素（滚动）不触发。「开始转化」固定在右栏目标材料框的最下方，目标列表在框内自行滚动。只有短屏内容超出时才启用整页滚动，选料和切换目标后恢复滚动位置，只有执行转化才收费。
- 手机图鉴使用两列预览，详情正文可滚动；遗物仓库也改为滚动（三列、取消分页与空位补齐），保留并排详情及其滚动。这里未实施列表/详情分离路由。
- 手机独立剧情文字脱离1600×900整幅构图缩放，改为标题工具栏、滚动正文、滚动选项与继续按钮。正文25、人物名26、说明23，均不再缩字塞框；换段回到正文/选项开头。LOG独立铺满画布、正文22，仍只读并暂停推进。桌面保留原美术构图。
- 教程战斗面板根据提示条的真实高度避让，手机及桌面均不再假定提示条固定不超过88高。

字号和尺寸均为Godot逻辑单位，不等同于Android dp/sp；最终观感与触控舒适度仍需真机校准。未开放150%倍率、未增加独立文字倍率设置。

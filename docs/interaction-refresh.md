# 交互刷新与资源预热

2026-10-18，内容版本保持 `godot-flow-v02-23`。本次属于表现层修复，不修改规则、存档结构或随机流。当次数据与验收见[交互延迟修复验证](../evidence/interaction-fix-verification.md)。

战斗页面自己处理选中牌抬起、预览与确认按钮；`battle_selection` 回调只同步 app/当前 HUD 的 UI 状态。视角按钮更新现有镜头、图标及提示。两条路径都检查当前 HUD 对应的规则/布局签名；模型状态已变化时回退完整刷新。

游戏中的设置、帮助、合成、建造、木筏详情与图鉴可在保留底层 HUD 的情况下创建、替换或移除独立 `GameModalLayer`。真实规则状态、profile、结算或布局尺寸/倍率变化仍完整重建。首页、回廊和独立剧情层保留原完整刷新路径。

打开模态层时记录各按钮原来的 disabled 值，禁用底层手牌和木筏交互处理并停用镜头输入。关闭时恢复原值，更新所有底层 BasePage（含内嵌事件页）的 revision/UI 上下文，并重新报价木筏操作。记录使用弱引用，旧模态子树脱离后释放；不跨规则状态缓存整张面板。模态内发生完整重建后也保留可恢复的木筏交互。`HudNotice` 在局部刷新时同步当前消息，避免旧错误残留。

局内高频道具动作可保留现有页面结构，只更新受影响区域：战斗动作在同一战斗、敌人未死亡、手牌/筏格/增益结构未变时只更新生命、AP、护盾、意图、日志与可用性；准备阶段打捞在同阶段、同面板、筏格拓扑不变且无奖励动画时只同步状态标签、策略和手牌投影；工作台投入原料与更换转化目标是纯 UI 操作，只更新槽位、数量、目标样式、输出预览和执行按钮，不提交 dispatch。阶段切换、敌人死亡、结构变化、模态层、奖励批次或兼容性检查失败时仍走完整重建。选中牌、悬浮、拖拽等手势状态不属于规则状态，不进入存档。实测数值、两轮样本与未覆盖范围见[局内局部刷新记录](../evidence/ingame-stalls-20261020.md)；工作台 tab 切换仍由页面内部整体重建，不在已优化范围。

手牌按下时保存固定指针位置 `press_origin`。短按移动阈值以此判断，不随卡牌渐变位置改变；静止松开可完成原卡点击。真实移动、拖拽、窗口失焦、触摸取消、禁用牌和外部松开仍有原有防护。该位置仅属于当前 UI 手势，不进入存档。

图形启动后异步预热合成首页最多八张本地图片：ResourceLoader 后台请求，检查完成状态后每帧最多接收一路资源，并交给原 AssetCatalog 缓存/图集路径管理。未完成的请求不会被强制等待；页面若提前索取素材，仍走原同步载入回退。owner 移除后排空已发请求而不继续缓存给失效界面。headless 启动跳过自动预热。此机制不下载文件，也不操作场景或规则随机状态。

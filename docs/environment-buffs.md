# 环境 Buff（Godot v13）

2026-10-16 正式接入。原设计来源：`V0.2/环境与移动结果.md`；标准档25%触发率、75%负面比例、权重和效果数值沿用旧试测，困难和噩梦按[难度表](difficulty.md)提高负面基础概率，尚不代表最终平衡。规则状态和随机均可保存，所有实际操作走 `GameSession.dispatch()`。

最多同时3环境、其中负面最多2个，待生效也占额度。同种刷新期限不叠数值；同类雾只保留最高级，低级不覆盖高级；迷雾Ⅲ与混乱不共存。不合法的显式效果返回失败，整个 dispatch 回滚；随机池排除不合法项。

## 生命周期与导航

轮初海况当轮生效，节点 `AddBuff` 从下一航次生效。轮末在夜间结束后、弃牌前计时一次；战斗和夜间调查不额外计时。当前有效状态被节点刷新时记录 pending_refresh，本轮结束后获得完整的新持续次数。

候选实体和迷雾遮蔽结果在生成时固定。公开投影使用 full/detailsHidden/typeOnly/unknown；隐藏候选不带真实节点ID、敌人、选项、费用、奖励或变体。侦察仅揭示既有内容，不重新生成候选。固定剧情站、层末Boss完整可见且免偏航，不能浪费定向支付；当前候选只有一个时同样没有偏航风险。

- `scout {id: visit_id}`：导航阶段支付SAN8，支付后至少保留1；已揭示或完整候选不能重复支付。
- `fix_heading {}`：导航存在偏航风险时支付木头1、0 AP，仅保护本次移动，不跨轮。
- 灯塔新增“请求航向导引”：需完好且有燃料的灯，0 AP，不消耗燃料；下一航次全部候选公开，混乱偏航率从25%降至10%。原木料/恢复/离开选项保留。这是本轮接入决定。

旧潮汐遗物潮纹镜片、定向骨针仍未启用，不提供虚假使用次数；当前开放的六种潮汐遗物不包含导航改写效果，见[潮汐遗物契约](collectible-effects.md)。迷雾Ⅲ和逆流已具备通用 `AddBuff` 接口和完整处理，默认不进入随机池，当前也未新增强制风险事件来源。

## 状态、接口与表现

`core/environment_rules.gd` 管理生命周期、导航和公开投影；`content/data/environments.json` 定义名称、描述、类别、持续与权重。`state.buffs` 每项为 `{id,active_from,remaining,pending_refresh}`；`state.environment` 保存轮初/轮末标记、候选可见性、已侦察候选、定向、导引、逆流首次操作及最近移动结果。

节点效果入口为 `AddBuff {id}` 和 `GuideNavigation {}`；没有向玩家/Agent开放任意授予环境的调试命令。ActionQuery 提供真实可执行的侦察与定向；Agent 观察新增 `environments` 与 `navigation`，不暴露规则随机或未来内容。战斗观察 `battle.enemy_direct_damage` 包含血月和当前伤害修正。

保存仍用schema2和xorshift32-godot-v1，内容升级为godot-flow-v02-13。v12及更旧明确拒绝；同版本保存验证环境ID、次数、互斥、数量、标记类型及候选可见性数据。

环境名称显示在左上“第 N / M 次航行 · 当前阶段”同一行的后面，待生效加文字标记；悬停显示效果、剩余次数和待刷新说明。原休整余裕也在同一行显示。移除顶部左右两块装饰底板；数值条和底部手牌/AP区保留。规则迷雾与场景视觉雾仍各自独立，不用视觉随机影响规则。

# 涌泉补给

2026-10-16经济试测，内容版本`godot-flow-v02-11` / schema2。

- 首轮保持自选1～5张或随机7张起手，不领取涌泉。
- 后续每轮在上一轮结算/整理通过、新轮设备生产后、开放导航前领取一次：**固定木头1＋随机基础资源1，共2张**。
- 随机池为木头、废铁、塑料、绳索、布条，等权20%；木头仍可再次抽到。每轮木头1～2份，期望1.2份。固定木头不消耗随机，随机牌只推进initial流1次。
- 领取后允许轮内超限；查看、读档不补发或重抽，终局/章节停点不额外领取。
- 本轮另将每张木头的灯燃料提高为2（每次移动消耗1），尸体仍为3；配方、容量、AP和设备产量不变。
- v10及旧内容明确拒绝，不静默迁移或重置。同版本恢复与随机一致性见`tests/test_spring_supply.gd`及[经济v11验证](../evidence/economy-v11-verification.md)。

v8/v9方案与当时试测仅作历史：[历史试测](../evidence/spring-wood-experiment.md)、[允许再抽木头补测](../evidence/spring-wood-repeat-allowed.md)、[v9采用记录](../evidence/spring-v9-adoption.md)。

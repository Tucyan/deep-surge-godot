# 涌泉补给

2026-10-16用户确认允许随机三张再次出现木头，内容版本 `godot-flow-v02-9` / schema2。当前正式试测规则：

- 首轮保持原起手选择，不领取涌泉。
- 后续每轮在上一轮结算/整理通过、新轮设备生产后、开放导航前领取一次：**固定木头1份＋随机基础资源3张，共4张**。
- 随机池为木头、铁、塑料、绳索、布条，五种各20%，有放回；允许重复且可再次抽到木头。每轮木头1～4份，期望1.6份。三次随机抽样使用现有initial流，固定木头不消耗随机数。
- 新补给入手后本轮可超限行动，直到本轮结束再检查容量；读档、看界面不会补发或重抽。
- 终局和章节停点不额外领取；配方、转化、灯燃料、容量、AP均保持原规则。
- 开发阶段不兼容旧存档：v8及更旧版本明确拒绝，不迁移；当前版本保存/恢复正常。

此前对照结果见[历史试测](../evidence/spring-wood-experiment.md)及[允许再抽木头补测](../evidence/spring-wood-repeat-allowed.md)。旧排除木头方案的采用记录保留为历史，本次v9落地验证见[最新采用记录](../evidence/spring-v9-adoption.md)。

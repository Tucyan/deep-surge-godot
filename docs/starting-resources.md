# 起手资源选择

2026-10-14 用户规则修订，适用于 Godot V0.2 剧情及挑战模式。

选定出身与种子，点击「开始航程」后进入资源选择界面，此时不创建游戏、不消耗随机数、不写新局存档。可返回修改出身/种子，保留资源选择。资源为木头、废铁、塑料、绳索、布条，每类最多2张，总计最多5张。

选择1～5张时按钮为「正式开始」，只发放选择的牌，不补齐。零选择时按钮为「随心所欲」，以5张基础配额加额外2张，等权随机发放7张资源并开始；随机模式不受自选每类2张限制。首次无涌泉，既有局外购买补给仍按原规则单独发放。

命令 `new` 新增可选 `starting_resources: string[]`。空数组或省略表示随机7张；规则层校验资源种类、数量及每类上限，非法请求回滚。随机使用原 `initial` 随机流，固定种子可复现；自选不抽取起手随机流，不影响规则以外的视觉随机。出发、候选、后续补给规则不变。

UI 源 `pages/new_game_setup.gd`，资源图复用 `card.wood`、`card.iron`、`card.plastic`、`card.rope`、`card.cloth`，未新增外部图片。程序化资产 `ui.starting-resources` 记录在资产清单。

验证：`tests/test_starting_resources.gd`（先失败后通过），包含两模式、1张与5张自选、空选7张、种子复现、非法材料及数量回滚、UI限制与两种开始入口。GPU截图 `evidence/starting-resources-1280.png` 和 `starting-resources-1600.png`；完整固定种子挑战回归 `test_routes.gd` 通过。

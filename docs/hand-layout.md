# 手牌排列与资源叠牌

2026-10-15：设备牌长按后移出手牌区可拖到真实筏格安装；手牌区内仍排序，无效外部落点则回位。鼠标/触摸、取消、双击及规则收费关系见[直接交互](raft-direct-interaction.md)。

2026-10-14，分支 `codex/hand-layout-stacking`。这是表现设计，不改变卡牌规则。

- 设置新增「自动理牌」及「同类资源合并显示（叠牌）」，默认开启；开关独立写入 `user://hand-layout.cfg`，不写入游戏存档或随机流。
- 自动理牌依次排列生存、资源、货币、设备、行动、战斗、负面牌，同类按内容 ID 排列；相同 ID 保持原实例顺序。
- 只有 `kind=resource` 且非临时的同 ID 卡牌数量达到 4 张才合并显示；3 张及以下逐张展示，消耗至 3 张时自动展开；生存牌、战术牌、设备保持独立。卡面右下标记 `×数量`，描述也显示数量。
- 合并只减少显示卡面，实际手牌容量仍按规则计数。弃置叠牌每次只弃置当前代表的一张实例；剩余数量立即更新，制造继续使用原库存逻辑。
- 鼠标短按松开后执行原动作；设备卡在导航/准备/收尾双击自动安装至首个完好空位，消耗 1 AP，无空位/AP 时保留卡牌并提示。单击仍查看。按住 0.2 秒进入拖动，松开按目标插入位置排序，可在手牌区域外松开。叠牌整体移动；拖动不会使用或弃置卡牌。
- 完成不同位置的手动排序会关闭自动理牌，并保存该开关。手动顺序在当前应用内跨界面重建保持，新取得卡牌追加；新局清除顺序，应用重启后不恢复手动顺序。
- 取消叠牌会在所在位置展开原实例。Esc 或窗口失去焦点取消拖动；长按前移动超过 10 像素取消本次点击。键盘焦点与提交仍可用。
- 航行和战斗手牌共用模型；战斗排序保留未显示卡牌的相对顺序。选项切换与排序不修改 AP、时间、库存、容量或 RNG。

贝币余额大于零时显示一张 `coin` 货币卡，使用稳定 UID `coins`，全部贝币合占一张容量，数量大于一时显示 `×数量`。不受资源叠牌开关或四张阈值影响，可查看与拖动排序。商店仍按余额支付；归零后卡面消失。轮末操作显示「弃置全部 · 贝币」，点击弃置整份余额。战斗专用手牌不把货币当作出牌动作。

程序接口：`GameSession.view().hand` 在永久/临时实例之外投影余额卡，`quantity` 表示贝币数量；该卡来自 `state.coins`，不写入 `state.hand` 或存档，不消耗实例 ID 或随机流。库存支付、容量、统计和旧存档格式保持现有规则。视图中的条目数量不能直接作为容量。

程序化资产：`ui.hand.fan` v11（`presentation/hand_fan.gd`），`ui.hand.layout` v3（`presentation/hand_layout.gd`），`ui.item-card` v2 及 `ui.hand.stack-quantity` v1（`presentation/item_card.gd`）。贝币复用 `card.coin` 和数量徽章。数量徽章采用铜金边/深蓝底，与现有卡面字体及 W.GOLD 共用；没有新增外部图片或视觉随机种子。映射与源 hash 登记在 `assets/manifest.json`。

验证入口：`tests/test_hand_layout.gd`、`tests/test_hand_gestures.gd`、`tests/test_hand_fan.gd`、`tests/test_hand_click.gd`；实际渲染入口 `tests/hand_layout_visual.gd`。画面使用明确的超限测试夹具，不表示正常初始库存。证据见 `evidence/hand-layout-verification.md`。

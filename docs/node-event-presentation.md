手机当前隐藏插画栏，保留正文与选项两栏，选项栏宽420、操作字20；桌面继续以下三栏布局。详见[手机阅读布局](mobile-ui-readability.md)。

节点事件在story阶段自动显示，不需要点击右侧入口。flow_app把全视口纯色遮罩和事件页插入世界与HUD之间，并按 z 序分三层：

| z | 层 | 内容 |
| --- | --- | --- |
| 0 | 世界与随世界走的操作 | 3D 海面/木筏、视角复位、视角切换、打捞 · AP1 |
| 1 | 事件底板 | `NodeEventSurface` 半透明纯色 + 三栏事件页 |
| 2 | 常驻 HUD | 顶栏、菜单、环境状态、行动点、手牌顶栏与手牌、合成/转化 |

因此视角复位、视角切换、打捞这些按钮在事件阶段仍然存在、仍然绘制，只是被底板压暗并挡住输入（不做删除）；离开事件后自动恢复亮度和可操作。被覆盖期间它们的 `focus_mode` 设为 `FOCUS_NONE`，键盘也不会误触。顶部状态栏、菜单、行动点、手牌与合成入口在底板之上，保持可用。

事件页自2026-10-18起为三栏，不再使用单一右侧框：

| 栏位 | 节点名 | 内容 |
| --- | --- | --- |
| 立绘 | `NodeEventArt` | 事件插画，按内容字段→怪物图→节点类型→剧情场次映射 |
| 文本 | `NodeEventProse` | 小标题、事件标题、事件说明/结果；预选时改为选项标题与选项说明 |
| 选项 | `NodeEventOptions` | 只放按钮，不再显示标题和说明 |

三栏共用同一事件容器：左右各留56，普通事件顶边124，教程事件顶边226为提示条留位；底边距视口328，避开行动点和手牌。立绘与文本分配剩余宽度，选项内容宽332加边框内距。窗口使用 canvas_items 拉伸并随UI缩放调整可用逻辑尺寸。文本与选项各自使用 ScrollContainer，内容较多时在栏内滚动，不撑大事件容器。

立绘不做强制美术约定：先读 `node.art` / `scene.art`，该 AssetId 若没有实体文件（占位）就跳过；其次按 `node.monster` 取 `enemy.*` 怪物图（透明底、等比完整显示）；再按节点类型取剧情插画（`opening.image.*`，按 `scenes.json` 的 display_region 裁掉黑边后铺满）；最后回落到默认海面插画。剧情场次另有 `ART_BY_SCENE` 覆盖表。没有节点专用立绘，新增美术后只需给内容加 `art` 字段，不改代码。

文本栏按 `story_step` 显示：intro 显示事件说明，choice 额外追加上一阶段结果与怪物生命/意图，result 只显示结果文字。剧情模式显示场次名与 `当前行/总行数`。文本顶部对齐，底部留白放提示。

选项栏只显示选项按钮，用等量弹性间隔均匀分布，按钮不再堆在顶部、底部不再留整块空白。栏顶固定一行：左侧说明文字「请做出选择」，右侧仅在预选时出现「取消选择」。按钮仍由原生 Button 承担文字、禁用原因、焦点与键鼠输入，长名与费用自动换行。

选项采用两步选择：首次点击只进入预选，右侧该选项文字变为「确认」，文本栏换成该选项的标题、说明、消耗与方式；再次点击同一选项才提交真实命令。预选时选项栏右上角出现红字「取消选择」，无按钮背景、边框或装饰，点击退出预选并恢复事件说明；手机保留56逻辑像素高的触控区域。该行高度在两种状态下都保留（左侧「请做出选择」始终显示），因此取消文字出现/消失不会推动其他选项的位置。

「继续」「跳过文字」「结束节点」「继续剧情/完成这段剧情」「迎战」「离开遭遇」「进入商店」是一步动作，点击即提交，不进入预选。

预选时若选项带目标筏格，会在木筏上高亮该格；取消预选或关闭事件时清除高亮。高亮复用事件遮罩下的专用拾取代理，不写规则状态。

规则阶段、AP、选项条件、结果命令与随机流保持原契约；三栏布局、预选状态、取消按钮都是表现状态，不进入 GameState，也不写入存档。验证见 [事件三栏验证](../evidence/node-event-ui-verification.md)。

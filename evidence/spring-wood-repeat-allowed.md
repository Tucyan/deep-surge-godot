新增方案：固定木头1，再从木头/铁/塑料/绳索/布条五资源池等概率、有放回抽3张。每轮总4张，木头至少1、最多4，期望1.6；其他材料期望合计2.4。排除木头版本为恰好1木头＋3其他。

## 方法与结果

沿用[首轮对照](spring-wood-experiment.md)的8种子、空白Profile、愚者、随机7张起手、两种公开动作策略与3次initial随机抽样。新增16局挑战＋1局剧情，同前一方案的16＋1局配对；整个研究累计85局、776组补给配对组成检查通过。输入仍使用v7归档以维持实验条件，v8正式实现已经与排除木头实验方案数值一致。不能把v7对照trace当成v8存档载入。

| 指标 | 排除木头 | 允许木头 |
| --- | --- | --- |
| 基础生存策略通关 | 7/8 | 8/8 |
| 扩建策略通关 | 8/8 | 8/8 |
| 扩建组平均材料转化次数 | 4.375 | **2.500** |
| 扩建组平均打捞次数 | 5.875 | **4.875** |
| 扩建组基础四设备齐备平均航次 | **4.50** | 5.00 |
| 扩建组终点六种设备齐备 | 8/8 | 8/8 |
| 扩建组六设备且两项生产Ⅱ级 | **8/8** | 7/8 |
| 扩建组平均弃木头份数 | **0.125** | 2.000 |
| 基础组平均弃牌操作次数 | 26.750 | **22.875** |

允许木头平均减少约43%的转化操作，但不是所有指标均优：非木头供给比排除版减少20%，基础设备齐备平均晚0.5轮，少一局达到全部生产升级目标，木头弃置略增加。两种方案的建设卡点都未归零。平均转化次数是每局全部目标的转化动作，不代表所有输入都来自涌泉。

两局配对剧情均完成15站；排除版59次弃牌操作，允许版40次。剧情含固定教学补给、可能重复安装设备，单种子结果只提示容量与整理压力，不作稳定胜率或建设平衡结论。

## 建议

若目标是减少被迫转化和整理、让木头同时承担燃灯/维修/建设，**倾向允许随机三张再次出现木头**，继续保持五资源等权，不额外提高木头权重。它保留保底，又提供少量自然结余，且不像固定2木那样明显集中供给。

若目标是最快、最确定地完成整套生产升级，排除木头版本仍有优势。8种子小样本不能证明允许版全面优于排除版；建议作为下一轮版本选择，而非最终平衡结论。正式运行规则仍按已确认的[涌泉规则](../docs/spring-supply.md)，本次未二次切换。

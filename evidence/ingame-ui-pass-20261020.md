# 局内界面整理：商店 / 战斗 / 合成 / 转化 / 仓库 / 事件

类型：验证记录。仅对 2026-10-20 当次工作树负责；全部改动位于表现层，规则、存档字段与随机流未变。

## 范围

| 界面 | 改动 |
|---|---|
| 商店 | 「购买货物 / 出售手牌」切换从正文第一行移到顶栏（与标题同一行）；删除底部「离开商店」按钮，离开统一由右上角 X 触发（映射到 `shop_leave`）；出售页页码栏在只有一页时不再显示，按钮不再拉满整行 |
| 战斗 | 右栏去掉「战斗记录」标题与日志面板，只保留「第 N 回合」和「跳过当前回合 / 放弃战斗」两个按钮；战斗记录折叠成与回合数同一行的文字按钮（`战斗记录 ›`），点开为深色半透明全屏遮罩 + 历史列表，可点「关闭」或点遮罩退出 |
| 配方合成 | 取消翻页与底部页码栏，桌面四列、手机三列一次列出全部配方并纵向滚动；说明文字移到材料库存下方 |
| 资源转化 | 去掉「投入 1 张」按钮和「快捷转化」按钮：点材料卡（图标，带 ＋ 角标）加一张，点「开始转化」槽位里的材料减一张；按下后移动超过 14 逻辑像素（滚动）不触发。删除顶部说明条、转化汇率与当前转化摘要；「开始转化」固定在右栏目标材料框最下方，目标列表在框内自行滚动 |
| 工作台 | 「?」说明按钮按右上角 X 的实际触控尺寸（桌面 44、手机 60）左移 8～12 逻辑像素排布，两端不再重叠 |
| 遗物仓库 | 电脑与手机统一为滚动：单元格固定 92×148（桌面 5 列、手机 3 列），一次列出全部持有物，取消分页与空位补齐 |
| 节点事件（仅手机） | 说明 / 选择 / 结果三个步骤的底边从「距视口 328」改为「距视口 18」，覆盖手牌区；手机事件阶段隐藏手牌托盘、手牌顶栏（行动点/容量）与右下「合成/转化」入口。**桌面保持原样**：底边仍为 328，手牌、行动点与合成入口照常显示 |

## 执行环境

Godot 4.7.2 stable，Windows，OpenGL Compatibility（RTX 4060 Laptop）。截图窗口 2520×1080（21:9，`mobile=true`、`ui_scale=1.25`、`free_aspect=true`，逻辑画布 1680×720）；测试另含 1280×720 / 1600×900 桌面画布与 125% UI。
